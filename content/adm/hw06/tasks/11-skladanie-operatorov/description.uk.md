**Приклади 23 і 24.** $T_1 \circ T_2$ означає «спочатку $T_2$, потім $T_1$», тобто $[T_1 \circ T_2] = [T_1][T_2]$.

23) $T_1(x_1, x_2) = (x_1 + 2x_2,\; -2x_1 + 3x_2)$, $T_2(x_1, x_2) = (3x_1,\; -2x_1 + x_2)$

24) $T_1(x_1, x_2, x_3) = (4x_2,\; x_1 + 2x_2,\; -x_1 + 3x_2)$, $T_2(x_1, x_2, x_3) = (x_2 - 2x_3,\; 3x_1,\; -2x_1 + x_2)$
