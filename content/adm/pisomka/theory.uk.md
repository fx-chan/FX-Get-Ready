## Однорідні координати

Поворот, відбиття й масштабування лінійні: $\mathbf{x} \mapsto \mathbf{Lx}$. **Паралельне перенесення на $(a, b)$** — це $x' = x + a$, $y' = y + b$; воно не лінійне, бо зсуває й початок координат. Розв'язання: точку $(x, y)$ записуємо як $(x, y, 1)$, а кожне відображення $\mathbf{x} \mapsto \mathbf{Lx} + \mathbf{t}$ — як матрицю $3\times3$:

$$\begin{bmatrix}\mathbf{L}&\mathbf{t}\\\mathbf{0}&1\end{bmatrix},\qquad
\mathbf{T}(a, b) = \begin{bmatrix}1&0&a\\0&1&b\\0&0&1\end{bmatrix},\qquad
\mathbf{R}_\theta = \begin{bmatrix}\cos\theta&-\sin\theta&0\\\sin\theta&\cos\theta&0\\0&0&1\end{bmatrix}$$

Тепер перенесення — це звичайний добуток матриць, тож його можна поєднувати з іншими відображеннями. Книжка в розділі 10.9 записує перенесення також як додавання $\mathbf{P}' = \mathbf{P} + \mathbf{T}$; множенням — це її вправа 7.

::: drill d8-homogenne

**Порядок:** спочатку $T_1$, потім $T_2$, потім $T_3$ означає $\mathbf{M} = \mathbf{M}_3\mathbf{M}_2\mathbf{M}_1$. Матриця, що виконується **першою, стоїть праворуч**.

::: quiz
Точку спочатку переносять, а потім повертають. Який добуток правильний?
- [ ] $\mathbf{T}\mathbf{R}$
- [x] $\mathbf{R}\mathbf{T}$
- [ ] байдуже
> На вектор спочатку діє найближча до нього матриця: $\mathbf{R}(\mathbf{T}\mathbf{x})$. Перенесення і поворот у загальному випадку не комутують.
:::

### Перетворення навколо іншої точки та відносно іншої прямої

Схема завжди однакова: **перенеси в початок, виконай, поверни назад.**

- поворот навколо точки $\mathbf{c}$: $\mathbf{T}(\mathbf{c})\,\mathbf{R}_\theta\,\mathbf{T}(-\mathbf{c})$,
- масштабування із центром у $\mathbf{c}$: $\mathbf{T}(\mathbf{c})\,\mathbf{S}\,\mathbf{T}(-\mathbf{c})$,
- відбиття відносно прямої, що не проходить через початок координат: перенесіть будь-яку її точку в початок, відбийте, перенесіть назад.

Відбиття відносно прямої через початок координат під кутом $\theta$ — це $\mathbf{H}_\theta$ з розділу 4.9; із напрямним вектором $(a, b)$: $$\mathbf{H} = \frac{1}{a^2 + b^2}\begin{bmatrix}a^2 - b^2&2ab\\2ab&b^2 - a^2\end{bmatrix}$$ Для прямої $y = 2x$ напрям $(1, 2)$ і $\mathbf{H} = \frac15\begin{bmatrix}-3&4\\4&3\end{bmatrix}$.

::: drill d8-rotacia-bod

### Що складене відображення насправді робить

Для ізометрії $\mathbf{x} \mapsto \mathbf{Lx} + \mathbf{t}$ досить подивитися на $\det\mathbf{L}$:

| $\det\mathbf{L}$ | відображення | перевірка |
|---|---|---|
| $1$, $\mathbf{L} = \mathbf{I}$ | перенесення | немає нерухомої точки |
| $1$, $\mathbf{L} \ne \mathbf{I}$ | поворот | єдина нерухома точка: $(\mathbf{I} - \mathbf{L})\mathbf{p} = \mathbf{t}$ |
| $-1$ | відбиття | $\mathbf{M}^2 = \mathbf{I}$ |
| $-1$ | ковзне відбиття | $\mathbf{M}^2$ — перенесення на подвоєний вектор ковзання |

Середина відрізка між точкою та її образом для відбиття і ковзного відбиття лежить **на осі**. Площа фігури множиться на число $|\det\mathbf{L}|$.

::: quiz
Два відбиття відносно паралельних прямих на відстані $d$ дають
- [ ] поворот на $180^\circ$
- [x] перенесення на $2d$
- [ ] відбиття
> $\det\mathbf{L} = (-1)(-1) = 1$ і лінійна частина дорівнює $\mathbf{I}$, отже це перенесення.
:::

## Власні числа: скорочення

Порядок дій із ДЗ 07 зберігається: $p(\lambda) = \det(\lambda\mathbf{I} - \mathbf{A})$, власні числа, базис для кожного $\lambda$, потім $\mathbf{P}$. На важких завданнях допоможуть скорочення:

- **перевірка:** сума власних чисел $= \operatorname{tr}\mathbf{A}$, добуток $= \det\mathbf{A}$,
- **однакові суми в рядках:** якщо кожен рядок має суму $s$, то $(1, 1, \dots, 1)$ — власний вектор для числа $s$,
- **ранг 1:** якщо $\mathbf{A} - c\mathbf{I} = \mathbf{u}\mathbf{w}^{\top}$, власні числа — це $c$ ($n-1$ разів) і $c + \mathbf{w}^{\top}\mathbf{u}$,
- **степені:** $\mathbf{A}^k = \mathbf{P}\mathbf{D}^k\mathbf{P}^{-1}$; для $\mathbf{N} = \mathbf{u}\mathbf{w}^{\top}$ маємо $\mathbf{N}^2 = (\mathbf{w}^{\top}\mathbf{u})\mathbf{N}$.

::: quiz
Кожен рядок матриці $3\times3$ має суму 7. Що відомо без обчислень?
- [x] 7 — власне число з вектором $(1, 1, 1)$
- [ ] $\det\mathbf{A} = 7$
- [ ] $\operatorname{tr}\mathbf{A} = 7$
> $\mathbf{A}(1,1,1)^{\top}$ — це вектор сум рядків, тобто $7\cdot(1,1,1)^{\top}$.
:::

## Степеневий метод

Шукає **домінантне** власне число, тобто число з найбільшим модулем, без розв'язання характеристичного рівняння.

Чому це працює: якщо $\mathbf{x}_0 = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \dots$, то $$\mathbf{A}^k\mathbf{x}_0 = \lambda_1^k\left(c_1\mathbf{v}_1 + c_2\left(\frac{\lambda_2}{\lambda_1}\right)^k\mathbf{v}_2 + \dots\right)$$, а члени з $|\lambda_i / \lambda_1| < 1$ зникають. Швидкість визначає відношення $|\lambda_2 / \lambda_1|$.

Книжка (розділ 9.2) описує два варіанти. Теореми 9.2.1 і 9.2.2 стосуються **симетричної** матриці з додатним домінантним числом і старту, не перпендикулярного до відповідного власного підпростору.

**З евклідовим масштабуванням:** $\mathbf{x}_0$ — одиничний вектор, $$\mathbf{x}_k = \frac{\mathbf{A}\mathbf{x}_{k-1}}{\lVert\mathbf{A}\mathbf{x}_{k-1}\rVert},\qquad \lambda^{(k)} = \mathbf{A}\mathbf{x}_k\cdot\mathbf{x}_k$$

**Із масштабуванням за максимумом:** $\max(\mathbf{x})$ — найбільший **модуль** компоненти (без знака), $\mathbf{x}_0$ — будь-який ненульовий вектор, $$\mathbf{x}_k = \frac{\mathbf{A}\mathbf{x}_{k-1}}{\max(\mathbf{A}\mathbf{x}_{k-1})},\qquad \lambda^{(k)} = \frac{\mathbf{A}\mathbf{x}_k\cdot\mathbf{x}_k}{\mathbf{x}_k\cdot\mathbf{x}_k}$$

Вираз $\frac{\mathbf{Ax}\cdot\mathbf{x}}{\mathbf{x}\cdot\mathbf{x}}$ — це **відношення Релея**. Воно не залежить від множника вектора, тому обидва варіанти дають однакові оцінки $\lambda^{(k)}$, якщо стартують з одного напряму. Перший веде до одиничного власного вектора, другий — до вектора з найбільшою компонентою 1.

$$\mathbf{A} = \begin{bmatrix}4&1\\1&4\end{bmatrix},\ \mathbf{x}_0 = \begin{bmatrix}1\\0\end{bmatrix}:\quad
\mathbf{A}\mathbf{x}_0 = \begin{bmatrix}4\\1\end{bmatrix},\ \mathbf{x}_1 = \begin{bmatrix}1\\\frac14\end{bmatrix},\quad
\mathbf{A}\mathbf{x}_1 = \begin{bmatrix}\frac{17}{4}\\2\end{bmatrix},\ \mathbf{x}_2 = \begin{bmatrix}1\\\frac{8}{17}\end{bmatrix}$$

::: drill d8-mocninova

**Коли метод не працює:** два числа з однаковим модулем ($1$ і $-1$), комплексна пара або $\mathbf{x}_0$ без компоненти в напрямі $\mathbf{v}_1$. За від'ємного домінантного числа вектор на кожному кроці змінює знак, але $\lambda^{(k)}$ збігається правильно (примітка до теореми 9.2.1).

::: quiz
Власні числа: $6$, $-3$, $1$. Приблизно у скільки разів зменшується похибка за одну ітерацію?
- [x] у 2 рази
- [ ] у 6 разів
- [ ] у 3 рази
> $|\lambda_2/\lambda_1| = 3/6 = 1/2$. Друге за модулем число — це $-3$.
:::

## Визначник 7×7

Розписувати $7! = 5040$ доданків неможливо. Стратегія:

1. **Шукайте рядок або стовпець з єдиним ненульовим елементом** і розкладайте. Розмір зменшується на 1, стежте за знаком $(-1)^{i+j}$.
2. **Шукайте приховані блоки:** які рядки використовують лише ті самі стовпці? Якщо для групи індексів рядки й стовпці утворюють замкнений блок, визначник дорівнює добутку визначників блоків.
3. **Однакова перестановка рядків і стовпців** знак не змінює. Різні перестановки: знак — добуток знаків обох перестановок.
4. **Властивості:** $\det(k\mathbf{A}) = k^7\det\mathbf{A}$, $\det(\mathbf{A}^{\top}) = \det\mathbf{A}$, $\det(\operatorname{adj}\mathbf{A}) = (\det\mathbf{A})^{n-1}$.

$$\det\begin{bmatrix}1&0&2\\0&5&0\\3&0&4\end{bmatrix} = 5\cdot\begin{vmatrix}1&2\\3&4\end{vmatrix} = -10$$ Середній рядок і стовпець утворюють блок, решта — другий блок.

::: drill d8-det7

- [x] $-$
- [ ] $+$
> $(-1)^{3+6} = (-1)^9 = -1$.
:::

- [ ] $1$

## LU-розклад без помилок

1. Зведіть $\mathbf{A}$ до REF **без перестановки рядків**. Ведучі одиниці роблять $\mathbf{U}$ матрицею з одиницями на діагоналі.
2. У $\mathbf{L}$ записуйте: на діагональ обернене значення множника ведучої одиниці, під діагональ протилежне число до множника, що створив нуль.
3. $\mathbf{Ly} = \mathbf{b}$ згори вниз, $\mathbf{Ux} = \mathbf{y}$ знизу вгору.
4. **Перевірка:** $\mathbf{LU}$ дає $\mathbf{A}$, $\det\mathbf{A}$ = добуток діагоналі $\mathbf{L}$.

У домашньому завданні цей вигляд називається Краут. Дулітл має одиниці на діагоналі $\mathbf{L}$, його отримаєте перенесенням діагоналі в $\mathbf{U}$.

Один розклад годиться для кількох правих частин: стовпець $\mathbf{A}^{-1}$ отримаєте з правої частини $\mathbf{e}_j$.

**Нульовий півот не означає виродженої матриці.** Якщо другий півот дорівнює $t - 2$, розкладу без перестановки при $t = 2$ не існує, але матриця може бути невиродженою: досить розкладу PLU, $\mathbf{PA} = \mathbf{LU}$. Вироджена вона лише тоді, коли півот лишається нульовим після всіх можливих перестановок.

::: drill d8-lu

::: quiz

- [x] $-2$
- [ ] $\frac12$
> У $\mathbf{L}$ йде протилежне число до множника 2. Знак — найчастіша помилка.
