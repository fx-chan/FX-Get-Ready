Ізометрію видно з лінійної частини $\mathbf{L}$ і перенесення $\mathbf{t}$ у записі $\mathbf{x} \mapsto \mathbf{Lx} + \mathbf{t}$: $\det\mathbf{L} = 1$ означає поворот або перенесення, $\det\mathbf{L} = -1$ — відбиття або ковзне відбиття. **Нерухома точка** задовольняє $(\mathbf{I} - \mathbf{L})\mathbf{p} = \mathbf{t}$. Для відбиття $\mathbf{M}^2 = \mathbf{I}$, для ковзного відбиття — ні.
