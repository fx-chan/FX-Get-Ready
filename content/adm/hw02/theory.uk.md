## Лінійне рівняння і система

**Лінійне рівняння** з невідомими $x_1, \dots, x_n$ має вигляд $a_1x_1 + a_2x_2 + \dots + a_nx_n = b$, де $a_i, b$ — сталі. Невідомі стоять лише в **першому степені**, не перемножуються між собою й не є аргументами функцій.

| лінійні ✓ | нелінійні ✗ |
|---|---|
| $\pi x_1 - \sqrt2\,x_2 = 3^{1/3}$ — коефіцієнти можуть бути ірраціональними | $x_1x_2 = 3$ — добуток невідомих |
| $\cos\frac{\pi}{7}\,x - 4y = \log 3$ — $\cos\frac{\pi}{7}$ є числом | $\cos x - 4y = 0$ — невідома у функції |
| $y + 5 = 2x + 4^2$ — $4^2$ є сталою | $x^{2/3}$, $x^{-2}$, $\sqrt{y}$, $\sqrt{x^2} = \lvert x\rvert$ |

::: drill d2-linearna

**Система** з $m$ лінійних рівнянь із $n$ невідомими. **Розв'язок** — це набір із $n$ чисел, який задовольняє **всі** рівняння одночасно. Система **сумісна**, якщо має хоча б один розв'язок, інакше **несумісна**. Кожна система має або

1. **жодного** розв'язку, 2. **рівно один** розв'язок, або 3. **нескінченно багато** розв'язків — інше неможливо.

Геометрично для двох невідомих: кожне рівняння — це пряма. Прямі паралельні (жодного розв'язку), перетинаються (один) або збігаються (нескінченно багато). Для трьох невідомих кожне рівняння — площина. Те, що інших можливостей немає, стверджує теорема 1.6.1.

::: quiz
Чи може лінійна система мати рівно два розв'язки?
- [ ] так, напр. квадратне рівняння
- [x] ні — якщо розв'язків два, то їх нескінченно багато
- [ ] так, якщо в неї два рівняння
> Якщо $\mathbf{X}_1, \mathbf{X}_2$ — розв'язки, то й $\mathbf{X}_1 + c(\mathbf{X}_2 - \mathbf{X}_1)$ для кожного $c$ (доведення в задачі A++).
:::

## Розширена матриця

Систему записуємо в матричному вигляді $\mathbf{A}\mathbf{x} = \mathbf{b}$, де $\mathbf{A}$ — **матриця коефіцієнтів**, а $\mathbf{b}$ — **стовпець правих частин**. **Розширена матриця** — це $[\mathbf{A}\,|\,\mathbf{b}]$:

$$\begin{aligned} 2x_1 + 2x_3 &= 1 \\ 3x_1 - x_2 + 4x_3 &= 7 \\ 6x_1 - x_2 - x_3 &= 0 \end{aligned}
\quad\longrightarrow\quad \left[\begin{array}{ccc|c} 2&0&2&1\\ 3&-1&4&7\\ 6&-1&-1&0 \end{array}\right]$$

Відсутня невідома = коефіцієнт **0**. Кожен рядок — одне рівняння, кожен стовпець (крім останнього) — одна невідома.

::: drill d2-augmentovana

## Елементарні операції над рядками

Ці операції **не змінюють множину розв'язків**:

1. перестановка двох рядків $R_i \leftrightarrow R_j$,
2. множення рядка на **ненульове** число $R_i \to kR_i$, $k \ne 0$,
3. додавання кратного іншого рядка $R_i \to R_i + kR_j$.

> Порада на контрольну: 1 у лівому верхньому куті без дробів часто дає операція 3, напр. для першого стовпця
> $-3, 2, 0$ операція $R_1 + 2R_2$ дає значення $-3 + 4 = 1$.

::: quiz
Яка операція **не є** елементарною операцією над рядками?
- [ ] $R_2 \to R_2 - 5R_1$
- [ ] $R_1 \leftrightarrow R_3$
- [x] $R_2 \to 0\cdot R_2$
- [ ] $R_3 \to \frac{1}{2}R_3$
> Множити рядок можна лише на **ненульове** число — множення на нуль знищило б рівняння.
:::

## REF і RREF

**Ступінчастий вигляд (REF):**
- нульові рядки внизу,
- перший ненульовий елемент кожного ненульового рядка дорівнює **1** (ведуча одиниця, півот),
- ведуча одиниця нижчого рядка стоїть **правіше** від ведучої одиниці рядка над ним.

**Зведений ступінчастий вигляд (RREF):** REF, а ще в кожному стовпці з ведучою одиницею **всюди інде нулі**.

$$\underbrace{\begin{bmatrix}1&5&-3\\0&1&1\\0&0&0\end{bmatrix}}_{\text{REF}}\qquad
\underbrace{\begin{bmatrix}1&0&3&1\\0&1&2&4\end{bmatrix}}_{\text{RREF}}\qquad
\underbrace{\begin{bmatrix}1&2&3\\0&0&0\\0&0&1\end{bmatrix}}_{\text{ani jedno: nulový riadok nie je dole}}$$

RREF заданої матриці **єдиний**, REF — ні: різні послідовності операцій можуть дати різні REF, але позиції ведучих одиниць залишаються однаковими.

::: quiz
Чи є $\begin{bmatrix}1&2&0\\0&1&0\\0&0&0\end{bmatrix}$ у RREF?
- [ ] так
- [x] ні, лише в REF — над ведучою одиницею у 2-му стовпці стоїть 2
- [ ] не є навіть у REF
> Для RREF потрібно $R_1 \to R_1 - 2R_2$.
:::

## Як прочитати розв'язок із RREF

- **Ведучі змінні** — стовпці з ведучою одиницею; **вільні змінні** — решта стовпців.
- Вільні змінні прирівнюємо до параметрів $t, s, \dots$ і через них виражаємо ведучі.
- Рядок $[0\;0\;\dots\;0 \,|\, c]$ при $c \ne 0$ означає $0 = c$ → система **несумісна**.

$$\left[\begin{array}{ccc|c}1&0&2&3\\0&1&-1&1\\0&0&0&0\end{array}\right] \Rightarrow
\begin{cases} x_1 = 3 - 2t \\ x_2 = 1 + t \\ x_3 = t \end{cases},\quad t \in \mathbb{R}$$

Кількість параметрів = кількість невідомих − кількість ведучих одиниць. Набір параметричних рівнянь, з якого отримуємо всі розв'язки, — це **загальний розв'язок** системи.

::: drill d2-rref

## Метод Гаусса і метод Гаусса–Жордана

1. **Прямий хід (Гаусс):** стовпець за стовпцем створюємо ведучу одиницю та нулі під нею → **REF**.
2. Потім або **зворотна підстановка** (від останнього рівняння вгору), або
3. **зворотний хід (Гаусс–Жордан):** нулі також **над** ведучими одиницями → **RREF**, розв'язок лише прочитати.

$$\left[\begin{array}{cc|c}1&1&1\\4&3&2\end{array}\right] \xrightarrow{R_2 - 4R_1}
\left[\begin{array}{cc|c}1&1&1\\0&-1&-2\end{array}\right] \xrightarrow{-R_2}
\left[\begin{array}{cc|c}1&1&1\\0&1&2\end{array}\right] \xrightarrow{R_1 - R_2}
\left[\begin{array}{cc|c}1&0&-1\\0&1&2\end{array}\right]$$

Розв'язок: $x = -1$, $y = 2$.

::: drill d2-gauss

**Кількість розв'язків** читаємо з REF. Нехай $r = h(\mathbf{A})$ — кількість ненульових рядків (ранг), а $n$ — кількість невідомих.

| ситуація | результат |
|---|---|
| $h(\mathbf{A}) < h([\mathbf{A}\,|\,\mathbf{b}])$ | жодного розв'язку |
| $h(\mathbf{A}) = h([\mathbf{A}\,|\,\mathbf{b}]) = n$ | рівно один розв'язок |
| $h(\mathbf{A}) = h([\mathbf{A}\,|\,\mathbf{b}]) < n$ | нескінченно багато, $n - r$ параметрів |

::: quiz
Система з 3 рівнянь із 5 невідомими сумісна. Скільки в неї розв'язків?
- [ ] рівно один
- [x] нескінченно багато
- [ ] сказати не можна, може бути й один
> Ранг не більший за 3 < 5, тому залишаються щонайменше 2 вільні змінні.
:::

## Однорідні системи

Система $\mathbf{A}\mathbf{x} = \mathbf{0}$ **завжди сумісна** — має **тривіальний розв'язок** $\mathbf{x} = \mathbf{0}$. **Нетривіальний** розв'язок існує тоді й лише тоді, коли є вільна змінна, напр. завжди, коли **невідомих більше, ніж рівнянь**. Для квадратної $\mathbf{A}$: нетривіальний розв'язок існує тоді й лише тоді, коли $\det\mathbf{A} = 0$.

**Теорема 1.2.1 (про вільні змінні):** якщо однорідна система має $n$ невідомих, а RREF має $r$ ненульових рядків, то система має $n - r$ вільних змінних. **Теорема 1.2.2:** однорідна система, у якій невідомих більше, ніж рівнянь, має нескінченно багато розв'язків. Увага: неоднорідна система з більшою кількістю невідомих, ніж рівнянь, може бути несумісною; але якщо вона сумісна, то має нескінченно багато розв'язків.

::: drill d2-homogenny

::: quiz
Однорідна система з 4 рівнянь із 4 невідомими після вилучення має 3 ведучі одиниці. Тоді вона
- [ ] має лише тривіальний розв'язок
- [x] має нескінченно багато розв'язків (1 параметр)
- [ ] несумісна
> Однорідна система не може бути несумісною. 4 − 3 = 1 вільна змінна.
:::

## Системи з параметром і сталими

- З параметром ($\alpha$) вилучення виконуємо як зазвичай; проблема виникає, коли **півот містить параметр** і може дорівнювати 0. Розглядаємо випадки: півот $\ne 0$ → один розв'язок; півот $= 0$ → дивимось на праву частину (0 = 0 → нескінченно багато, 0 = ненульове → жодного).
- Для правих частин $a, b, c$ після вилучення отримуємо рядок $[0\;0\;0 \,|\, \text{výraz v } a,b,c]$; **умова сумісності** — вираз $= 0$.

$$\begin{aligned}x+3y-z&=a\\x+y+2z&=b\\2y-3z&=c\end{aligned}
\xrightarrow{R_2-R_1}\ -2y+3z = b-a \xrightarrow{+R_3}\ 0 = b - a + c \;\Rightarrow\; c = a - b$$

::: quiz
Після вилучення отримали останній рядок $[\,0\;\;0\;\;(\alpha-2)(\alpha+2) \,|\, \alpha - 2\,]$. При $\alpha = 2$ система
- [ ] не має розв'язків
- [x] має нескінченно багато розв'язків
- [ ] має рівно один розв'язок
> При $\alpha = 2$ рядок має вигляд $[0\;0\;0\,|\,0]$, рівняння зникає і з'являється вільна змінна. При $\alpha = -2$ маємо $[0\;0\;0\,|\,-4]$ — жодного розв'язку.
:::

## Нелінійні системи через заміну

Якщо невідомі трапляються лише у **виразах однакового вигляду** ($\sin\alpha$, $x^2$, $\frac1x$, …), уводимо нові невідомі ($u = \sin\alpha$, $X = x^2$, $u = \frac1x$), розв'язуємо лінійну систему й повертаємося назад. Увага на кількість розв'язків: $x^2 = 1$ дає $x = \pm1$, $\sin\alpha = 0$ дає на $[0, 2\pi]$ три кути $0, \pi, 2\pi$.

::: quiz
Після заміни $X = x^2, Y = y^2, Z = z^2$ маємо $X = 1, Y = 3, Z = 2$. Скільки розв'язків $(x, y, z)$ має початкова система?
- [ ] 1
- [ ] 3
- [x] 8
- [ ] 6
> Кожна невідома має 2 знаки: $2\cdot2\cdot2 = 8$.
:::
