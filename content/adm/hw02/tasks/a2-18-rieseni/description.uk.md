**Приклад 22 (A++).** Покажіть, що система $$\begin{aligned} \sin\alpha + 2\cos\beta + 3\tan\gamma &= 0 \\ 2\sin\alpha + 5\cos\beta + 3\tan\gamma &= 0 \\
-\sin\alpha - 5\cos\beta + 5\tan\gamma &= 0\end{aligned}$$ має 18 розв'язків для $0 \le \alpha, \beta, \gamma \le 2\pi$. Порядок дій: заміна → однорідна лінійна система → визначник → єдиний розв'язок $(0,0,0)$ → порахуйте кути.
