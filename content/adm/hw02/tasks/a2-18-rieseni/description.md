**Príklad 22 (A++).** Ukážte, že systém
$$\begin{aligned} \sin\alpha + 2\cos\beta + 3\tan\gamma &= 0 \\ 2\sin\alpha + 5\cos\beta + 3\tan\gamma &= 0 \\
-\sin\alpha - 5\cos\beta + 5\tan\gamma &= 0\end{aligned}$$
má 18 riešení pre $0 \le \alpha, \beta, \gamma \le 2\pi$. Postup: substitúcia → homogénny lineárny systém →
determinant → jediné riešenie $(0,0,0)$ → spočítajte uhly.
