**Príklady 19, 20, 21.** Pre systémy s parametrom nájdite hodnoty, pri ktorých systém nemá riešenie / má
nekonečne veľa riešení; podmienky konzistentnosti a riešenie s konštantami $a, b, c$.

Postup: urobte elimináciu s parametrom; problém nastane, keď sa pivot rovná nule. Ak žiadna hodnota
nevyhovuje, zaškrtnite **žiadna hodnota**.

19 a) $x + 2y - 3z = 4,\; 2x - y + 5z = 2,\; 4x + y + (\alpha^2 - 14)z = \alpha + 2$

19 b) $x + 2y + z = 2,\; 2x - 2y + 3z = 1,\; x + 2y - (\alpha^2 - 3)z = \alpha$

20 a) $x + 3y - z = a,\; x + y + 2z = b,\; 2y - 3z = c$ 20 b) $x + 3y + z = a,\; -x - 2y + z = b,\; 3x + 7y - z = c$

21 a) $2x + y = a,\; 3x + 6y = b$ 21 b) $x_1 + x_2 + x_3 = a,\; 2x_1 + 2x_3 = b,\; 3x_2 + 3x_3 = c$
