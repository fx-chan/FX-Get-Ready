## LU-розклад

Квадратну матрицю розкладаємо на добуток **нижньої** і **верхньої** трикутних матриць $\mathbf{A} = \mathbf{LU}$. Розклад існує, якщо $\mathbf{A}$ можна звести до ступінчастого вигляду **без перестановки рядків** (теорема 9.1.1). Він не єдиний.

**Порядок дій із книжки:**

1. Зведіть $\mathbf{A}$ до REF $\mathbf{U}$ без перестановок. Запам'ятайте множники, що створили ведучі одиниці, і множники, що створили нулі під ними.
2. На діагональ $\mathbf{L}$ поставте **обернене значення** множника, який створив ведучу одиницю.
3. Під діагональ $\mathbf{L}$ поставте **протилежне число** до множника, який створив нуль на цьому місці.

Отже, $\mathbf{U}$ має одиниці на діагоналі, а $\mathbf{L}$ — півоти. У домашньому завданні цей вигляд називається **Краут**. Вигляд **Дулітл** має одиниці на діагоналі $\mathbf{L}$:

| метод | $\mathbf{L}$ | $\mathbf{U}$ |
|---|---|---|
| **Краут** (порядок дій із книжки) | на діагоналі півоти | одиниці на діагоналі |
| **Дулітл** | одиниці на діагоналі | на діагоналі півоти |

$$\begin{bmatrix}2&1\\6&8\end{bmatrix} \xrightarrow{\frac12 R_1} \begin{bmatrix}1&\frac12\\6&8\end{bmatrix} \xrightarrow{R_2 - 6R_1} \begin{bmatrix}1&\frac12\\0&5\end{bmatrix} \xrightarrow{\frac15 R_2} \begin{bmatrix}1&\frac12\\0&1\end{bmatrix} = \mathbf{U},\qquad \mathbf{L} = \begin{bmatrix}2&0\\6&5\end{bmatrix}$$

Між виглядами переходимо перенесенням діагоналі. **Розклад LDU:** $\mathbf{A} = \mathbf{L}'\mathbf{D}\mathbf{U}$, де $\mathbf{L}'$ і $\mathbf{U}$ мають одиниці на діагоналі, а $\mathbf{D}$ діагональна. Дулітл — це $\mathbf{L}'(\mathbf{DU})$, Краут — це $(\mathbf{L}'\mathbf{D})\mathbf{U}$.

::: drill d7-lu

> Якщо під час вилучення на місці півота з'являється **0**, LU-розкладу без перестановки рядків не існує. Рядки переставляємо наперед:
> **розклад PLU**, $\mathbf{PA} = \mathbf{LU}$, де $\mathbf{P}$ — матриця перестановки. Система тоді має вигляд $\mathbf{LUx} = \mathbf{Pb}$.

## Застосування LU-розкладу

**Система** $\mathbf{Ax} = \mathbf{b}$ ↔ $\mathbf{LUx} = \mathbf{b}$:
1. позначимо $\mathbf{y} = \mathbf{Ux}$,
2. розв'язуємо $\mathbf{Ly} = \mathbf{b}$ **прямою підстановкою** (згори вниз),
3. розв'язуємо $\mathbf{Ux} = \mathbf{y}$ **зворотною підстановкою** (знизу вгору).

Перевага: розклад відокремлює $\mathbf{A}$ від $\mathbf{b}$, для багатьох правих частин він рахується лише раз.

- **Обернена матриця:** $\mathbf{A}^{-1} = (\mathbf{LU})^{-1} = \mathbf{U}^{-1}\mathbf{L}^{-1}$.
- **Визначник:** $\det\mathbf{A} = \det\mathbf{L}\cdot\det\mathbf{U}$ = добуток діагоналей; у Дулітла $\det\mathbf{L} = 1$, у Краута $\det\mathbf{U} = 1$.

::: quiz
Розклад Дулітла має $\mathbf{U}$ з діагоналлю $2, -3, 4$. Чому дорівнює $\det\mathbf{A}$?
- [ ] 3
- [x] $-24$
- [ ] 24
> $\det\mathbf{L} = 1$ (одиниці на діагоналі), $\det\mathbf{U} = 2\cdot(-3)\cdot4 = -24$.
:::

## Власні числа і власні вектори

Ненульовий вектор $\mathbf{x}$ є **власним вектором** квадратної матриці $\mathbf{A}$, якщо $$\mathbf{Ax} = \lambda\mathbf{x}$$ для деякого числа $\lambda$ — **власного числа**. Перетворення не змінює напрям $\mathbf{x}$, а лише розтягує/стискає його (або обертає при $\lambda < 0$). Нульовий вектор власним не є.

::: drill d7-vlastny-vektor

**Характеристичний многочлен** і **характеристичне рівняння** (теорема 5.1.1): $$p(\lambda) = \det(\lambda\mathbf{I} - \mathbf{A}) = 0$$ Корені — це власні числа. Для $2\times2$: $p(\lambda) = \lambda^2 - \operatorname{tr}(\mathbf{A})\,\lambda + \det\mathbf{A}$. Загалом: **сума** власних чисел = $\operatorname{tr}\mathbf{A}$, **добуток** = $\det\mathbf{A}$.

::: drill d7-charakteristicky

::: quiz
Чи має матриця $\begin{bmatrix}1&2\\-2&-1\end{bmatrix}$ дійсні власні числа?
- [ ] так, $\pm 1$
- [x] ні, $p(\lambda) = \lambda^2 + 3$, власні числа — $\pm i\sqrt3$
- [ ] так, $0$ і $0$
> $\operatorname{tr} = 0$, $\det = -1 + 4 = 3$, тобто $\lambda^2 + 3 = 0$.
:::

**Власний підпростір** для $\lambda$ = усі розв'язки $(\lambda\mathbf{I} - \mathbf{A})\mathbf{x} = \mathbf{0}$ (однорідна система, ДЗ 02). Його **базис** — незалежні власні вектори, вимірність = $n - \operatorname{hodnosť}(\lambda\mathbf{I} - \mathbf{A})$ (**геометрична кратність**). **Алгебраїчна кратність** = кратність кореня в $p(\lambda)$. Справджується $1 \le$ геометрична $\le$ алгебраїчна.

::: drill d7-vlastny-priestor

**Без обчислень:**
- трикутна / діагональна матриця: власні числа — це **елементи діагоналі** (теорема 5.1.2),
- $\lambda = 0$ є власним числом $\iff$ $\det\mathbf{A} = 0$ ($\mathbf{A}$ вироджена, теорема 5.1.4),
- $\mathbf{A}^k$ має власні числа $\lambda^k$, $\mathbf{A}^{-1}$ має $\frac1\lambda$, $\mathbf{A} - s\mathbf{I}$ має $\lambda - s$ (з тими самими векторами),
- геометричні перетворення: відбиття $\{1, -1\}$, проєкція $\{1, 0\}$, розтяг $k$ $\{k, k\}$, поворот на $\theta \ne 0, \pi$ у $\mathbb{R}^2$ не має дійсних власних чисел.

::: quiz
Які власні числа має ортогональна проєкція на вісь $x$ у $\mathbb{R}^2$?
- [ ] лише 1
- [x] 1 (вектори на осі $x$) і 0 (вектори на осі $y$)
- [ ] $1$ і $-1$
> Вектор на осі $x$ не змінюється ($\lambda = 1$), вектор на осі $y$ переходить у нуль ($\lambda = 0$).
:::

## Подібність матриць

$\mathbf{B}$ **подібна** до $\mathbf{A}$ (означення 1 у розділі 5.2), якщо $\mathbf{B} = \mathbf{P}^{-1}\mathbf{AP}$ для деякої оборотної $\mathbf{P}$. Подібні матриці мають однаковий **визначник, слід, ранг, характеристичний многочлен і власні числа** (власні вектори можуть відрізнятися). Якщо якийсь інваріант відрізняється, матриці не подібні. Однак рівність усіх інваріантів ще не гарантує подібності.

::: quiz
$\det\mathbf{A} = -1$ і $\det\mathbf{B} = -2$. Чи можуть $\mathbf{A}$ і $\mathbf{B}$ бути подібними?
- [x] ні, подібні матриці мають однаковий визначник
- [ ] так, якщо мають однаковий слід
- [ ] вирішити неможливо
> $\det(\mathbf{P}^{-1}\mathbf{AP}) = \det\mathbf{P}^{-1}\det\mathbf{A}\det\mathbf{P} = \det\mathbf{A}$.
:::

## Діагоналізація

$\mathbf{A}$ ($n\times n$) **діагоналізовна**, якщо подібна до діагональної матриці: $$\mathbf{P}^{-1}\mathbf{AP} = \mathbf{D} = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$$ Це справджується **тоді й лише тоді** (теорема 5.2.1), коли $\mathbf{A}$ має $n$ лінійно незалежних власних векторів — вони утворюють стовпці $\mathbf{P}$ (у тому самому порядку, що й власні числа в $\mathbf{D}$).

Порядок дій: 1) власні числа, 2) для кожного $\lambda$ базис власного підпростору, 3) якщо разом $n$ векторів → $\mathbf{P}$, інакше матриця **не є** діагоналізовною. Досить: **$n$ різних власних чисел ⇒ діагоналізовна** (теорема 5.2.2). Загалом $\mathbf{A}$ діагоналізовна тоді й лише тоді, коли для кожного власного числа геометрична кратність дорівнює алгебраїчній (теорема 5.2.4).

::: drill d7-diagonalizacia

::: quiz
$\mathbf{A} = \begin{bmatrix}5&0&0\\1&5&0\\0&1&5\end{bmatrix}$ має власне число 5 з алгебраїчною кратністю 3. Ранг $5\mathbf{I} - \mathbf{A}$ дорівнює 2. Чи діагоналізовна $\mathbf{A}$?
- [ ] так, вона трикутна
- [x] ні, власний підпростір має вимірність $3 - 2 = 1 < 3$
- [ ] так, має лише одне власне число
> Потрібні були б 3 незалежні власні вектори, а маємо лише 1.
:::

## Степені матриці

Якщо $\mathbf{A} = \mathbf{PDP}^{-1}$, то $$\mathbf{A}^k = \mathbf{P}\mathbf{D}^k\mathbf{P}^{-1},\qquad \mathbf{D}^k = \operatorname{diag}(\lambda_1^k, \dots, \lambda_n^k),$$ бо $\mathbf{P}^{-1}\mathbf{P}$ між множниками скорочується. Працює й для від'ємних $k$ (якщо $\lambda_i \ne 0$). Якщо $\mathbf{A}^2 = \mathbf{I}$ (власні числа $\pm1$), то парні степені дорівнюють $\mathbf{I}$, а непарні $\mathbf{A}$.

::: quiz
Власні числа $\mathbf{A}$ — це $1, -1, -1$, і $\mathbf{A}$ діагоналізовна. Чому дорівнює $\mathbf{A}^{100}$?
- [ ] $\mathbf{A}$
- [x] $\mathbf{I}$
- [ ] $-\mathbf{I}$
> $\mathbf{D}^{100} = \operatorname{diag}(1, 1, 1) = \mathbf{I}$, тобто $\mathbf{A}^{100} = \mathbf{PIP}^{-1} = \mathbf{I}$.
:::
