Напишіть функцію `void mocnina(double x, int n)`, яка виводить таблицю степенів від `x^1` до `x^n`. Ввід — дійсне `x` і ціле `n`. Рядок `i` має вигляд `x^i = y`; `x` і `y` з 2 знаками після коми.

### Приклад вводу
```
3.0 4
```
### Вивід
```
3.00^1 = 3.00
3.00^2 = 9.00
3.00^3 = 27.00
3.00^4 = 81.00
```
