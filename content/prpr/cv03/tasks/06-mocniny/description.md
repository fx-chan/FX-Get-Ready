Napíšte funkciu `void mocnina(double x, int n)`, ktorá vypíše tabuľku mocnín `x^1` až `x^n`.
Vstupom je reálne `x` a celé `n`. Riadok `i` má tvar `x^i = y`; `x` aj `y` na 2 desatinné miesta.

### Ukážka vstupu
```
3.0 4
```
### Výstup
```
3.00^1 = 3.00
3.00^2 = 9.00
3.00^3 = 27.00
3.00^4 = 81.00
```
