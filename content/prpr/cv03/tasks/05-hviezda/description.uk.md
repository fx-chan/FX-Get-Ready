Зчитайте `N`. Якщо `N < 1`, `N > 15` або парне, виведіть `Zly vstup`. Інакше намалюйте зірку `N×N` із символів `*` і пробілів: зірочки на обох діагоналях, у середньому рядку та середньому стовпці (поєднання фігур «X» і «+»).

### Приклад вводу
```
9
```
### Вивід (крапка = пробіл)
```
*...*...*
.*..*..*.
..*.*.*..
...***...
*********
...***...
..*.*.*..
.*..*..*.
*...*...*
```

У виводі справжні **пробіли**; пробіли в кінці рядка під час перевірки ігноруються.
