## Повторення: for і while

```c
for (inicializacia; podmienka; krok) { telo; }

inicializacia;                 // те саме через while
while (podmienka) { telo; krok; }
```

## Значення, що повертає scanf

`scanf` повертає **кількість успішно зчитаних елементів** або `EOF` в кінці вводу. Завдяки цьому можна читати, поки є дані — навіть якщо наперед невідомо, скільки їх.

```c
int x, pocet = 0;
while (scanf("%d", &x) == 1)    // читай, поки вдається зчитати число
    pocet++;
```

## Повторне зчитування do-while

```c
int n;
do {
    scanf("%d", &n);
} while (n < 0);        // повторюй, поки n не стане невід'ємним
```

## Вкладені цикли

```c
for (int r = 1; r <= n; r++) {        // рядки
    for (int s = 1; s <= r; s++)      // стовпці
        printf("*");
    printf("\n");
}
```

## Функції

Функція має **тип повернення**, **ім'я**, **параметри** і **тіло**. Якщо вона визначена лише після `main`, її треба заздалегідь **оголосити** (прототип).

```c
#include <stdio.h>

double obvod(double r);            // прототип (оголошення)

int main(void) {
    printf("%.2f\n", obvod(2.0));  // виклик
    return 0;
}

double obvod(double r) {           // визначення
    return 2 * 3.14 * r;
}
```

- параметри передаються **за значенням** — функція отримує копію й оригінал не змінює,
- функція `void` нічого не повертає; `return;` може завершити її раніше,
- локальні змінні існують лише під час виклику (крім `static`).

::: quiz
Що виведе програма?

```c
void zvys(int x) { x = x + 1; }
int main(void) { int a = 5; zvys(a); printf("%d", a); }
```
- [x] 5
- [ ] 6
- [ ] помилка компіляції
> Функція отримала копію значення. Щоб змінити оригінал, потрібен вказівник (Практика 5).

### Блоки та область видимості

Блок — це частина коду в `{ }`. Змінна, визначена в блоці, діє **від місця визначення до кінця блоку**. Внутрішній блок може визначити змінну з таким самим ім'ям — тоді вона **перекриє** зовнішню.

```c
int x = 1;                 // глобальна
int main(void) {
    int x = 2;             // локальна в main, перекриває глобальну
    {
        int x = 3;         // внутрішній блок
        printf("%d\n", x); // 3
    }
    printf("%d\n", x);     // 2
    for (int i = 0; i < 3; i++) { }
    // i тут уже не існує
    return 0;
}
```

- `main` теж функція: повертає `int` (0 = успіх) і може мати параметри `int argc, char *argv[]`,
- `return` завершує функцію негайно (навіть посеред циклу),
- функцію, визначену після місця виклику, треба заздалегідь оголосити прототипом — інакше GCC 15 видає помилку.

::: quiz
Що виведе `int a = 1; { int a = 5; a++; } printf("%d", a);`?
- [x] 1
- [ ] 5
- [ ] 6
> Внутрішнє `a` — це інша змінна, яка зникає в кінці блоку. Зовнішнє `a` залишається 1.
:::
