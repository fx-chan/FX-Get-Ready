Створіть функцію `nacitaj`, яка зчитує два дійсних числа й повертає їх **через аргументи** (вказівники), і функцію `vypocitaj`, яка отримує довжини сторін і через аргументи повертає площу й периметр. Виведіть площу й периметр із **3 знаками після коми**.

### Приклад вводу
```
3.5 4.75
```
### Вивід
```
Obsah: 16.625
Obvod: 16.500
```
