Vytvorte funkciu `nacitaj`, ktorá načíta dve reálne čísla a vráti ich **cez argumenty**
(ukazovatele), a funkciu `vypocitaj`, ktorá dostane dĺžky strán a cez argumenty vráti obsah a obvod.
Vypíšte obsah a obvod na **3 desatinné miesta**.

### Ukážka vstupu
```
3.5 4.75
```
### Výstup
```
Obsah: 16.625
Obvod: 16.500
```
