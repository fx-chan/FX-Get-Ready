*Extra úloha k prednáške P4.* Na vstupe je text (viac riadkov). Spočítajte slová (oddelené bielymi
znakmi) a nájdite najdlhšie slovo (pri zhode prvé). Slová majú najviac 100 znakov.

### Ukážka vstupu
```
Toto je ukazkovy
text na pocitanie slov
```
### Výstup
```
Pocet slov: 7
Najdlhsie slovo: pocitanie (9)
```
