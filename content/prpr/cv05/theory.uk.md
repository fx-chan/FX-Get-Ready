## Перетворення типів

- **неявне**: в `int + double` значення `int` автоматично перетворюється на `double`,
- під час присвоєння «меншому» типу може загубитися інформація: `int i = 3.99;` → `i == 3`,
- **явне** (приведення типу): `(double)a / b` — ділення виконується в дійсних числах.

::: quiz
`int a = 7, b = 2;` Яке значення має `(double)(a / b)`?
- [ ] 3.5
- [x] 3.0
- [ ] 4.0
> Дужки обчислюються першими: `7 / 2 == 3` (цілочисельно), і лише потім 3 перетворюється на `3.0`. Правильно: `(double)a / b`.
:::

## Вказівник

Вказівник — це змінна, яка зберігає **адресу** іншої змінної.

```c
int x = 10;
int *p = &x;      // & = адреса змінної x
*p = 20;          // * = розіменування: запиши за адресою, на яку вказує p → x == 20
int *q = NULL;    // нікуди не вказує; неініціалізований вказівник небезпечний
printf("%p\n", (void *)p);   // вивід адреси
```

::: quiz
`int x = 3; int *p = &x; *p = *p + 4;` Яке значення має `x`?
- [ ] 3
- [x] 7
- [ ] адресу x + 4
> `*p` — це сама змінна `x`; `x = 3 + 4`.
:::

### Вказівник на вказівник, void *, segmentation fault

```c
int x = 5;
int *p = &x;
int **pp = &p;         // адреса вказівника
**pp = 7;              // *pp це p, **pp це x  →  x == 7

void *v = &x;          // універсальний вказівник: може вказувати на що завгодно
int *q = (int *)v;     // перед розіменуванням його треба привести до типу; *v — помилка
double d = 2.5;
v = &d;                // той самий void * тепер вказує на double
```

**Segmentation fault** = програма звернулася до пам'яті, яка їй не належить. Типові причини: розіменування `NULL` або неініціалізованого вказівника, запис далеко за кінець масиву, використання пам'яті після `free`, нескінченна рекурсія. На цьому сайті це виглядає як помилка виконання.

```c
int *p;          // неініціалізований — вказує «кудись»
*p = 3;          // невизначена поведінка, часто segfault
int *r = NULL;
*r = 3;          // завжди помилка
```

Кілька вказівників можуть вказувати на те саме місце — зміну через один видно через усі.

::: quiz
`int x = 1; int *p = &x; int **pp = &p;` Що змінить `x` на 9?
- [ ] `*pp = 9;`
- [x] `**pp = 9;`
- [ ] `pp = 9;`
> `*pp` — це вказівник `p` (присвоєння змінило б адресу), `**pp` — це вже сама `x`.
:::

### Вказівник на функцію

Ім'я функції — це її адреса. Вказівник на функцію дає змогу вибрати, яка функція викликається, лише під час виконання.

```c
int sucet(int a, int b) { return a + b; }

int (*f)(int, int);    // f — вказівник на функцію (int, int) -> int; дужки навколо *f обов'язкові
f = sucet;             // або f = &sucet;
printf("%d\n", f(2, 3));          // або (*f)(2, 3)

int *g(int, int);      // УВАГА: це функція, яка повертає int *
```

::: quiz
Що оголошує `double (*h)(double);`?
- [ ] функцію `h`, яка повертає вказівник на `double`
- [x] вказівник `h` на функцію, яка приймає і повертає `double`
- [ ] масив `double`
> Дужки `(*h)` кажуть, що `h` — вказівник; після нього йде список параметрів функції.
:::

## Передавання за вказівником

Функція може змінити змінну того, хто її викликає, якщо отримає її адресу — так вона «повертає» кілька значень одразу.

```c
void vymen(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
...
vymen(&x, &y);
```

> **Ніколи** не повертайте адресу локальної змінної — після завершення функції вона зникає.

## Рядки

Рядок — це масив `char`, що закінчується символом `'\0'`. `"ahoj"` займає **5** байтів.

```c
char s[20] = "ahoj";
char meno[50];
scanf("%49s", meno);           // одне слово, без &, макс. 49 символів
fgets(meno, sizeof meno, stdin);   // увесь рядок разом із '\n'
```

| `string.h` | значення |
|---|---|
| `strlen(s)` | довжина без `'\0'` |
| `strcpy(dst, src)` | копіювання (dst має бути досить великим) |
| `strcat(dst, src)` | дописування в кінець |
| `strcmp(a, b)` | 0 якщо однакові, <0 / >0 за абеткою |
| `strchr(s, c)` | вказівник на перше входження символу або `NULL` |
| `strstr(s, t)` | вказівник на перше входження підрядка або `NULL` |

`ctype.h`: `isdigit`, `isalpha`, `isspace`, `toupper`, `tolower`.

::: quiz
Як правильно порівняти два рядки `a` і `b`?
- [ ] `a == b`
- [x] `strcmp(a, b) == 0`
- [ ] `strlen(a) == strlen(b)`
> `a == b` порівнює адреси масивів, а не вміст.
:::

Інші функції з `string.h`: `strncpy`, `strncat`, `strncmp` (працюють щонайбільше з `n` символами — частина рядка), `strrchr` (останнє входження символу — робота з рядком від кінця).

### Рядкова стала і масив

```c
char pole[] = "ahoj";   // масив із 5 символів, вміст можна змінювати: pole[0] = 'A';
char *s = "ahoj";       // вказівник на сталу в пам'яті лише для читання
// s[0] = 'A';          // невизначена поведінка (часто аварія)
const char *t = "ahoj"; // правильний запис — компілятор заборонить зміну
```

### Порядковий і форматований ввід/вивід із рядка

| функція | що робить |
|---|---|
| `fgets(s, n, stdin)` | зчитує рядок (разом із `'\n'`), макс. `n-1` символів — безпечно |
| `puts(s)` | виводить рядок і додає `'\n'` |
| `gets(s)` | **не використовувати** — не перевіряє розмір, вилучена з мови |
| `sscanf(s, "%d", &x)` | як `scanf`, але читає з рядка `s` |
| `sprintf(s, "%d", x)` | як `printf`, але записує в рядок `s` (`snprintf` з обмеженням розміру) |

```c
char riadok[100];
fgets(riadok, sizeof riadok, stdin);
riadok[strcspn(riadok, "\n")] = '\0';   // вилучення '\n' у кінці
```

### Перетворення рядка на число, перевірка символів

```c
#include <stdlib.h>
int i = atoi("123");            // 123   (за помилки повертає 0 — помилку не відрізнити)
double d = atof("3.14");        // 3.14
char *koniec;
long l = strtol("42abc", &koniec, 10);   // 42, koniec вказує на "abc" — знаємо, де перетворення закінчилось
```

`ctype.h`: `isdigit(c)` цифра, `isalpha(c)` літера, `isalnum(c)`, `isspace(c)` пробільний символ, `isupper(c)`/`islower(c)`, `toupper(c)`/`tolower(c)` повертає змінений символ.

### Масив рядків

```c
char mena[3][20] = {"Jan", "Eva", "Ola"};   // 2D-масив символів: 3 рядки по макс. 19 символів
const char *dni[] = {"Po", "Ut", "St"};      // масив вказівників на рядкові сталі
printf("%s %c\n", mena[1], dni[2][0]);       // Eva S
```

### Часті помилки з рядками

- забуте місце для `'\0'`: `char s[4] = "ahoj";` не має завершення,
- `s = "text";` для масиву — потрібно `strcpy(s, "text");`,
- `scanf("%s", s)` без обмеження довжини → переповнення масиву; використовуйте `%49s`,
- порівняння `==` замість `strcmp`, `'a'` (символ) і `"a"` (рядок із 2 байтів).

::: quiz
Що поверне `atoi("12abc")`?
- [ ] 0
- [x] 12
- [ ] помилку
> `atoi` перетворює початкову частину, схожу на число, а решту ігнорує. Де перетворення закінчилося, покаже лише `strtol`.
:::
