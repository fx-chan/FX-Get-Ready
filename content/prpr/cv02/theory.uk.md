## Пріоритет операторів

Від найвищого до найнижчого (вибірка):

| група | оператори |
|---|---|
| унарні | `++ -- ! - (typ) sizeof &` |
| мультиплікативні | `* / %` |
| адитивні | `+ -` |
| порівняння | `< <= > >=` |
| рівність | `== !=` |
| логічні | `&&`, потім `||` |
| умовний | `? :` |
| присвоєння | `= += -= *= /= %=` |

Якщо не впевнені — **використовуйте дужки**.

::: quiz
Яке значення має `1 + 2 * 3 > 6 && 0`?
- [ ] 1
- [x] 0
- [ ] 7
> `2*3 = 6`, `1+6 = 7`, `7 > 6` дорівнює 1, але `1 && 0` дорівнює 0.
:::

## Умовний вираз `?:`

```c
int max = (a > b) ? a : b;      // якщо a > b, результат a, інакше b
printf("%s\n", n % 2 == 0 ? "parne" : "neparne");
```

## if – else if – else

```c
if (body >= 92)      printf("A\n");
else if (body >= 83) printf("B\n");
else if (body >= 74) printf("C\n");
else                 printf("FX\n");
```

> **Увага:** `if (x = 5)` — це присвоєння (завжди істина), порівняння — `if (x == 5)`.

## switch

`switch` порівнює цілочисельне значення (також `char`) зі сталими. Без `break` виконання **провалюється** в наступну гілку.

```c
switch (znak) {
    case '+': printf("%d\n", a + b); break;
    case '-': printf("%d\n", a - b); break;
    case 'x':
    case '*': printf("%d\n", a * b); break;   // дві гілки спільно використовують код
    default:  printf("Zle zadana volba.\n");
}
```

::: quiz
Що виведе `int x = 1; switch (x) { case 1: printf("A"); case 2: printf("B"); break; default: printf("C"); }`?
- [ ] `A`
- [x] `AB`
- [ ] `ABC`
- [ ] `C`
> У гілці `case 1` бракує `break`, тому виконується і `case 2`. Там `break` завершує switch.
:::

## Цикли

```c
// while: умова перевіряється ПЕРЕД тілом (тіло може не виконатися жодного разу)
while (n > 0) { sucet += n % 10; n /= 10; }

// do-while: тіло виконується ХОЧА Б раз (зручно для повторного зчитування)
do { scanf("%d", &n); } while (n < 0);

// for: ініціалізація; умова; крок
for (int i = 1; i <= n; i++) sucet += i;
```

- `break` — негайно завершує цикл
- `continue` — пропускає решту тіла й переходить до наступної ітерації

**Оператор кома** `,` обчислює вирази зліва направо, результат — значення **останнього**. Найчастіше використовується у `for`, коли потрібно кілька змінних:

```c
for (i = 0, j = n - 1; i < j; i++, j--)   // два індекси йдуть назустріч
    { int t = a[i]; a[i] = a[j]; a[j] = t; }

x = (a = 2, a + 3);                        // x == 5
```

Поради: `for` коли відома кількість повторень, `while` коли повторюємо, поки справджується умова, `do-while` коли тіло має виконатися хоча б раз. Не змінюйте керівну змінну `for` в тілі циклу.

::: quiz
Яке значення має `x` після `x = (1, 2, 3);`?
- [ ] 1
- [ ] 6
- [x] 3
> Оператор кома повертає значення останнього виразу. (Без дужок `x = 1, 2, 3;` присвоїло б 1 — присвоєння має вищий пріоритет за кому.)
:::

::: quiz
Скільки разів виконається тіло `for (i = 0; i < 10; i += 3)`?
- [ ] 3
- [x] 4
- [ ] 10
- [ ] 3.33
> `i` = 0, 3, 6, 9 → чотири рази; при `i = 12` умова не справджується.
:::

## Статичний одновимірний масив

```c
#define N 11
int pole[N];                      // N елементів, індекси 0 .. N-1
int p[5] = {1, 2, 3};             // решта заповнюється нулями: {1,2,3,0,0}
for (int i = 0; i < N; i++)
    scanf("%d", &pole[i]);
```

- розмір статичного масиву має бути відомий під час компіляції (стала),
- C **не перевіряє** межі масиву: `pole[N]` — помилка, яку компілятор не виявить,
- кількість елементів: `sizeof(p) / sizeof(p[0])`,
- масиви **не можна** порівняти `==` чи скопіювати `=` — це треба робити поелементно в циклі.

```c
int a[3] = {1, 2, 3}, b[3];
// b = a;          помилка компіляції
for (int i = 0; i < 3; i++) b[i] = a[i];   // правильне копіювання
```

::: quiz
`int a[5];` — яке звернення помилкове?
- [ ] `a[0]`
- [ ] `a[4]`
- [x] `a[5]`
> Індекси від 0 до 4. `a[5]` поза масивом — невизначена поведінка.
:::
