Načítajte **11** celých čísel do jednorozmerného poľa. Postupnosť je správna, ak:

- prvé číslo je z intervalu ⟨0, 10⟩,
- každé ďalšie číslo nie je **väčšie ako dvojnásobok** predchádzajúceho ani **menšie ako polovica**
  predchádzajúceho čísla.

Vypíšte `Postupnost je spravna` alebo `Postupnost nie je spravna`.

### Ukážka vstupu
```
3 5 7 9 12 20 30 40 41 70 100
```
### Výstup
```
Postupnost je spravna
```
