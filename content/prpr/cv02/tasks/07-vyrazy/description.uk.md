Напишіть програму, яка обчислює й виводить результати двох виразів:

```c
e / --a * b++ / c++
a %= b = d = 1 + e / 2
```

Ввід — **два рядки**, кожен із п'ятьма цілими числами `a b c d e`. Перший вираз обчисліть для значень із першого рядка, другий — для значень із другого рядка. Вивід — два рядки з результатами. Обґрунтуйте результати (порядок обчислення, префікс і постфікс, цілочисельне ділення).

### Приклад вводу
```
6 2 2 4 5
6 2 2 4 5
```
### Вивід
```
1
0
```
