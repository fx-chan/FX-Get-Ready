Napíšte program, ktorý vypočíta a vypíše výsledky dvoch výrazov:

```c
e / --a * b++ / c++
a %= b = d = 1 + e / 2
```

Vstupom sú **dva riadky**, každý s piatimi celými číslami `a b c d e`. Prvý výraz vyhodnoťte pre
hodnoty z prvého riadku, druhý pre hodnoty z druhého riadku. Výstupom sú dva riadky s výsledkami.
Výsledky si zdôvodnite (poradie vyhodnocovania, prefix vs. postfix, celočíselné delenie).

### Ukážka vstupu
```
6 2 2 4 5
6 2 2 4 5
```
### Výstup
```
1
0
```
