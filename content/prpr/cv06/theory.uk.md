## Статичне і динамічне виділення пам'яті

| | статичне (`int a[100];`) | динамічне (`malloc`) |
|---|---|---|
| розмір | відомий під час компіляції | визначається під час виконання (напр. зчитується `n`) |
| де | стек / сегмент даних | купа (heap) |
| звільнення | автоматично | **ви** через `free` |

```c
#include <stdlib.h>

int n;
scanf("%d", &n);
int *a = malloc(n * sizeof(int));       // n елементів типу int
if (a == NULL) {                        // пам'яті може не бути
    printf("Malo pamate\n");
    return 1;
}
for (int i = 0; i < n; i++) a[i] = i;
free(a);                                // повернути пам'ять
a = NULL;                               // захист від використання звільненої пам'яті
```

- `calloc(n, sizeof(int))` — як `malloc`, але **обнуляє** пам'ять,
- `realloc(p, nova_velkost)` — змінює розмір блоку (може його перемістити; повертає нову адресу),
- `memset(p, 0, n * sizeof(int))` (`string.h`) — швидке встановлення кожного **байта** блоку в значення (безпечно лише для 0; `memset(p, 1, ...)` не дасть в `int` одиниць).

```c
int *tmp = realloc(a, 2 * n * sizeof(int));
if (tmp == NULL) { free(a); return 1; }   // у разі невдачі старий блок лишається чинним
a = tmp;
```

### Динамічний масив і функції

Функція може створити масив і повернути адресу — або записати його через вказівник на вказівник:

```c
int *vytvor(int n) {                 // повертає адресу нового блоку
    return calloc(n, sizeof(int));
}

void vytvor2(int **p, int n) {       // змінює вказівник того, хто викликає
    *p = malloc(n * sizeof(int));
}

int *a = vytvor(10);
int *b;
vytvor2(&b, 10);
free(a); free(b);
```

> Повертати адресу **локального** масиву (`int pole[10]; return pole;`) не можна — він зникає разом із функцією.
> Динамічна пам'ять живе, доки ви її не звільните через `free`.

## Адресна арифметика

Додавання `1` до вказівника зсуває його на **один елемент** (а не на один байт).

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;            // ім'я масиву = адреса першого елемента
printf("%d\n", *(p + 2));   // 30 — те саме, що a[2] або p[2]
p++;                   // тепер вказує на a[1]
printf("%ld\n", (long)(&a[4] - p));   // різниця вказівників = 3 елементи
```

::: quiz
`int a[] = {1, 2, 3, 4}; int *p = a + 1;` Що таке `*(p + 2)`?
- [ ] 2
- [ ] 3
- [x] 4
- [ ] поза масивом
> `p` вказує на `a[1]`, `p + 2` — на `a[3]`, тобто 4.

### Порівняння вказівників, масив і вказівник

- вказівники в той самий масив можна порівнювати `<`, `==`: `p < q` означає, що `p` стоїть у масиві раніше,
- порівняння з `NULL`: `if (p == NULL)` або скорочено `if (!p)`,
- різниця `q - p` — це кількість **елементів** між ними (тип `ptrdiff_t`),
- `a[i]` — те саме, що `*(a + i)`; оператор `[]` — лише скорочений запис.

```c
for (int *p = a; p < a + n; p++)   // обхід масиву лише вказівником
    printf("%d ", *p);
```

Різниця між масивом і вказівником видна в `sizeof`:

```c
int a[10];
int *d = malloc(10 * sizeof(int));
sizeof(a);    // 40 — увесь статичний масив
sizeof(d);    // 8  — лише розмір вказівника! розмір блоку треба пам'ятати у змінній

void f(int pole[]) {     // масив як параметр — це насправді int *pole
    sizeof(pole);        // 8, а не розмір масиву → довжину треба передати окремим параметром
}
```

**Масив вказівників** — кожен елемент є вказівником, напр. на окремо виділений блок або рядок:

```c
char *slova[3];
slova[0] = malloc(10);    // кожен елемент має власну пам'ять (і власний free)
```

## Часті помилки

- **витік пам'яті (memory leak)** — забутий `free` (або втрачена адреса блоку),
- **висячий вказівник (dangling pointer)** — використання пам'яті після `free`,
- **подвійний `free`** того самого блоку,
- запис поза виділеним блоком (напр. забуте місце для `'\0'` у рядку: `malloc(strlen(s) + 1)`),
- `p = realloc(p, ...)` без перевірки — у разі невдачі втрачається початкова адреса (витік),
- `malloc(n)` замість `malloc(n * sizeof(int))` — виділяє байти, а не елементи.
