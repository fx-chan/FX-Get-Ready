Načítajte rozmery `n` (riadky) a `m` (stĺpce), potom `n·m` celých čísel. Vo funkcii
`int **alokuj_2D_pole(int n, int m)` dynamicky alokujte pole (pole ukazovateľov na riadky),
naplňte ho, vykreslite funkciou `void vypis_2D_pole(int **p, int n, int m)` (čísla v riadku oddelené
medzerou) a pamäť uvoľnite funkciou `void uvolni(int **p, int n)`.

### Ukážka vstupu
```
2
3
1
2
3
4
5
6
```
### Výstup
```
1 2 3
4 5 6
```
