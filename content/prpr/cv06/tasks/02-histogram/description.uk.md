Ввід — один рядок з **ім'ям файлу**. Для кожного рядка файлу порахуйте кількість окремих літер (великі й малі не розрізняйте) і виведіть таблицю:

- заголовок: `  #`, а потім літери від `A` до `Z`, кожна шириною 3 (`%3c`),
- для кожного рядка файлу: номер рядка шириною 3 (`%3d`) і кількості літер шириною 3 (`%3d`).

### Приклад вводу
```
subor.txt
```
### Файл subor.txt
```
Toto je ukazkovy subor.
V subore su pismena.
```
