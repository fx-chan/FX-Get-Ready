## Як виглядає комп'ютерний тест

Тест (напр. група A_1_1) продовжує **проєкт № 1**: у свій зданий проєкт ви допрограмовуєте нові функції, що активуються натисканням клавіші (напр. `j`, `x`).

Правила зі зразка тесту:

- працюєте **самостійно**, матеріали й Google заборонені,
- **не використовуйте глобальні змінні, структури і `goto`**,
- дані функції отримують **через аргументи** (динамічні масиви, 2D-масив рядків `char **`),
- якщо ви не здали проєкт, використовуєте задані заголовки функцій:

```c
void j(char **pole_Mer_Mod, char **pole_Typ_MV, double *hodnota, int velkost_pola);
void x(double *hodnota, int velkost_pola);
```

Тут обидві задачі зроблені **самостійними програмами**: `main` зчитує дані, які інакше мав би в пам'яті проєкт, і викликає вашу функцію. Оцінюється так само — точний вивід.


## На що звернути увагу

1. **Точний формат виводу** — кількість знаків після коми (`%.4f`), пробіли, крапки в кінці речень.
2. **Перевірка вводу** — «зчитуй k, доки воно не додатне»: `scanf` може повернути 0 (нечисловий ввід), тоді погане слово треба пропустити (`scanf("%*s")`), інакше програма зациклиться.
3. **Допоміжні функції** — середнє значення, відсоткова різниця, вибір значень одного модуля.
4. **Звільнення пам'яті** для кожного `malloc`.
5. Дійсні числа не порівнюйте через `==`, цифри з числа беріть через округлене ціле число.
