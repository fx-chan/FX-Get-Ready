## Алгоритм і парадигми

**Алгоритм** — це точний порядок дій, який за скінченну кількість кроків розв'язує задачу. Потрібні властивості:

| властивість | значення |
|---|---|
| однозначність | кожен крок точно визначений |
| детермінованість | наступний крок однозначно заданий |
| результативність | за скінченну кількість кроків приходить до результату |
| правильність | результат завжди коректний |
| ефективність | якнайменше часу й пам'яті (вимоги часто суперечливі) |

**Парадигми програмування**: процедурна (C, Pascal), об'єктно-орієнтована (Java, C++), функціональна (Lisp, Haskell), логічна (Prolog). Мова C **процедурна**: програма — це послідовність команд, які виконуються в записаному порядку, якщо керівна структура не визначає інакше; дані зберігаються в змінних, що змінюють значення під час роботи.

- [ ] детермінованість
- [x] результативність
- [ ] ефективність

:::

## Від вихідного коду до програми

Мова C **компільована**: вихідний код (`.c`) спочатку перекладається в машинний код, і лише потім запускається.

| крок | що робить | ключ `gcc` | результат |
|---|---|---|---|
| 1. препроцесор | вставляє `#include`, розгортає `#define`, вилучає коментарі | `-E` | `.i` |
| 2. компілятор | перекладає C в асемблер | `-S` | `.s` |
| 3. асемблер | асемблер → машинний код | `-c` | `.o` |
| 4. компонувальник | об'єднує файли `.o` і бібліотеки | (без ключа) | виконуваний файл |

```
gcc -Wall -o hello hello.c     # усе разом, результат: hello (hello.exe у Windows)
gcc -v hello.c                 # -v показує, що gcc робить на кожному кроці
./hello                        # запуск
```

> На цьому сайті код компілює сервер (GCC 15) — досить натиснути **Перевірити** / **Надіслати**.

## Структура програми

```c
#include <stdio.h>   // printf, scanf

int main(void) {
    printf("Hello world!\n");
    return 0;        // 0 = програма завершилася успішно
}
```

- `#include <stdio.h>` — підключає заголовковий файл стандартного вводу/виводу.
- `main` — точка входу програми. Повертає `int`.
- Кожна команда закінчується крапкою з комою `;`. `\n` — це кінець рядка.
- Коментарі: `// do konca riadku` і `/* viac riadkov */`. Коментарі `/* */` **не можна вкладати**: `/* a /* b */ c */` закінчується на першому `*/`, а `c */` — це помилка.

::: quiz

- [ ] двокрапка `:`
- [x] крапка з комою `;`
- [ ] новий рядок
> Кінець рядка для C нічого не означає — команди розділяє `;`.
:::

## Змінні та типи

Змінна має **тип**, **ім'я** та **значення**. Перед використанням її треба оголосити.

| тип | розмір (типово) | приклад | `printf` | `scanf` |
|-----|---|---------|----------|---------|
| `char` | 1 B | `'b'` | `%c` (символ), `%d` (код) | `" %c"` |
| `int` | 4 B | `10`, `-3` | `%d` | `%d` |
| `long` | 4–8 B | `123456L` | `%ld` | `%ld` |
| `float` | 4 B | `3.14f` | `%f` | `%f` |
| `double` | 8 B | `3.14` | `%f`, `%lf`, `%g` | `%lf` |

```c
int i = 10, j = 15;
char c = 'b';
double x = 3.1415926535;
printf("i = %d j = %d\n", i, j);
printf("c = %c | %d\n", c, c);   // c = b | 98  -- символ — це число з таблиці ASCII
```

**Модифікатори типів**: `unsigned` (без знака — вивільнений біт збільшує додатний діапазон), `signed` (типово), `short`, `long`, `long long`. Напр. `unsigned int` (`%u`), `long long` (`%lld`).

**Правила для імен**: починається з літери або `_`, далі лише літери, цифри та `_`; великі й малі літери розрізняються (`pom`, `Pom`, `POM` — три змінні); не може бути ключовим словом (`int for;` — помилка). Імена, що починаються з `_`, залиште системі.

**Глобальні та локальні змінні**: змінна, визначена поза функціями, **глобальна** — її бачить уся програма. Змінна, визначена в блоці `{ }`, **локальна** — існує лише в цьому блоці.

```c
int pocitadlo;          // глобальна, автоматично ініціалізована нулем

int main(void) {
    int j = 5;          // локальна в main; без ініціалізації мала б випадкове значення
    pocitadlo++;
    return 0;
}
```

## Ввід і вивід

`scanf` потрібна **адреса** змінної — тому `&`. `printf` отримує **значення**.

```c
int a, b;
scanf("%d %d", &a, &b);          // зчитує два цілих числа
printf("Sucet: %d\n", a + b);    // вираз прямо в printf, без допоміжної змінної
```

Форматування чисел

```c
double x = 3.14159;
printf("%.2f\n", x);    // 3.14       2 знаки після коми
printf("%8.3f|\n", x);  //    3.142|  ширина 8
printf("%g\n", 2.50);   // 2.5        лише значущі знаки після коми
printf("%3d|\n", 7);    //   7|       ціле число на 3 позиції
printf("100%%\n");      // 100%       символ % пишеться як %%
```

Escape-послідовності: `\n` новий рядок, `\t` табуляція, `\\` зворотна коса риска, `\"` лапки, `\'` апостроф.

> `%.1f` = один знак після коми; 2.25 · 2 = 4.5.

## Оператори

- арифметичні: `+ - * / %` — увага: `/` між двома `int` — це **цілочисельне ділення**: `7 / 2 == 3`, `7 % 2 == 1`
- `7 / 2.0 == 3.5` — досить, щоб один операнд був дійсним
- інкремент / декремент: `i++` (спочатку використовує, потім збільшує), `++i` (спочатку збільшує)
- присвоєння — це вираз: `a = b = 5;`, скорочено: `a += 3;` `a %= b;`
- операції порівняння `< <= > >= == !=` і логічні `&& || !` повертають `1` (істина) або `0` (хибність)

- [ ] 8
> `7 / 2` — цілочисельне ділення = 3, потім `3 * 2 = 6`.
:::

### Бітові оператори

Працюють з окремими бітами числа (не плутайте з логічними `&&`, `||`, `!`):

| оператор | значення | приклад (4 біти) |
|---|---|---|
| `&` | AND — 1, якщо обидва біти 1 | `0011 & 0101 = 0001` |
| `|` | OR — 1, якщо хоча б один біт 1 | `0011 | 0101 = 0111` |
| `^` | XOR — 1, якщо біти різні | `0011 ^ 0101 = 0110` |
| `~` | заперечення кожного біта | `~0101 = 1010` |
| `<<` | зсув ліворуч (= множення на 2ⁿ) | `0101 << 2 = 10100` (5 → 20) |
| `>>` | зсув праворуч (= цілочисельне ділення на 2ⁿ) | `0101 >> 1 = 0010` (5 → 2) |

```c
unsigned n = 5;                 // 101
int bit = (n >> k) & 1;         // значення k-го біта
n = n | (1u << k);              // встанови k-й біт в 1
n = n & ~(1u << k);             // обнули k-й біт
```

> `110 & 011 = 010` = 2. Увага: `6 && 3` дало б 1 (логічне AND), `6 | 3` = 7.

## Умова if

```c
char c;
scanf(" %c", &c);                 // пробіл перед %c пропускає пробільні символи
if (c >= 'A' && c <= 'Z')         // це велика літера?
    c = c + 'a' - 'A';            // зміна на малу (зсув в ASCII)
else
    printf("Nie je velke.\n");
```

Кілька команд у гілці → фігурні дужки `{ }`.
