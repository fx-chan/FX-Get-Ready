## Стандартний ввід і вивід

Кожна програма має три відкриті потоки: `stdin` (клавіатура), `stdout` (екран), `stderr` (помилки).

```c
int c = getchar();      // один символ зі stdin, у кінці вводу повертає EOF
putchar(c);             // один символ у stdout
```

> `getchar` повертає `int`, а не `char` — інакше `EOF` (-1) не можна було б відрізнити від звичайного символу.

```c
int c;
while ((c = getchar()) != EOF)   // класичний цикл: читай до кінця вводу
    putchar(c);
```

::: quiz
Чому результат `getchar()` зберігають в `int`?
- [ ] це швидше
- [x] щоб можна було відрізнити `EOF` від звичайних символів
- [ ] `char` не можна порівнювати
> `EOF` — значення поза діапазоном символів (зазвичай -1).
:::

## Робота з файлами

```c
FILE *f = fopen("data.txt", "r");     // "r" читання, "w" запис (перезаписує), "a" дописування
if (f == NULL) {                      // завжди перевіряйте!
    printf("Subor sa nepodarilo otvorit.\n");
    return 1;
}
int c;
while ((c = getc(f)) != EOF)          // getc/putc, fscanf/fprintf, fgets/fputs
    putchar(c);
fclose(f);                            // закрити = записати буфер і звільнити файл
```

| функція | що робить |
|---|---|
| `getc(f)`, `putc(c, f)` | символ із файлу / у файл |
| `fscanf(f, "%d", &x)` | як `scanf`, повертає кількість зчитаних елементів |
| `fprintf(f, "%d\n", x)` | як `printf` |
| `fgets(buf, n, f)` | увесь рядок (макс. `n-1` символів), у кінці повертає `NULL` |
| `rewind(f)` | назад на початок файлу |
| `ftell(f)` | поточна позиція у файлі (у байтах від початку) |
| `fseek(f, posun, odkial)` | переміщення позиції; `odkial` = `SEEK_SET` (початок), `SEEK_CUR` (поточна), `SEEK_END` (кінець) |
| `feof(f)` | ненульове, якщо вже була **спроба** читати за кінцем файлу |
| `ungetc(c, f)` | повертає зчитаний символ назад у буфер — наступне читання отримає його знову |
| `remove("a.txt")`, `rename("a.txt", "b.txt")` | видалення / перейменування файлу (0 = успіх) |
| `tmpfile()` | тимчасовий файл, який після закриття сам видаляється |

Усі режими `fopen`: `"r"` читання, `"w"` запис (створює / очищає), `"a"` дописування в кінець, `"r+"` читання й запис (файл має існувати), `"w+"`, `"a+"`. Двійкові файли відкриваються з `"rb"`/`"wb"` і читаються/записуються через `fread`/`fwrite`.

**Буфер**: вивід надсилається на диск не після кожного символу, а збирається в буферній пам'яті. Записується під час `fclose`, `fflush(f)` або коли буфер заповнений. Тому файл треба завжди закривати — і перевіряти, що `fclose(f) == 0`.

```c
fseek(f, 0, SEEK_END);          // у кінець файлу
long velkost = ftell(f);        // позиція в кінці = розмір файлу в байтах
rewind(f);                      // назад на початок

int c = getc(f);
if (c >= '0' && c <= '9') {
    ungetc(c, f);               // поверни цифру назад, нехай її зчитає fscanf
    fscanf(f, "%d", &x);
}
```

> `while (!feof(f)) { fscanf(...); }` — часта помилка: `feof` стає істинним лише **після** невдалого читання,
> тож останній запис обробляється двічі. Перевіряйте значення, що повертає функція читання.

> `sizeof(f)` — це розмір вказівника `FILE *`, а не файлу.
:::

## Функції на практиці

Розділіть програму на малі функції з однією задачею — напр. `zisti_prvocislo`, `reverzne_cislo`. Функція, що «відповідає так/ні», зазвичай повертає `1`/`0` (або за умовою `1`/`-1`).

```c
int je_parne(int n) {
    return n % 2 == 0;
}
```
