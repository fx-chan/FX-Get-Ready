Načítajte dve celé čísla (hranice intervalu) a vypíšte všetky prvočísla z intervalu, každé na
samostatnom riadku. Použite funkciu `int zisti_prvocislo(int cislo)`, ktorá vráti `1` pre prvočíslo,
inak `-1`. **Ošetrite hranice** — prvé číslo môže byť väčšie ako druhé. Ak v intervale nie je
žiadne prvočíslo, vypíšte `Prvocislo neexistuje`.

### Ukážka vstupu
```
1 4
```
### Výstup
```
2
3
```
