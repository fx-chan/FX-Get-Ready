Зчитайте два цілих числа (межі проміжку) і виведіть усі прості числа з проміжку, кожне в окремому рядку. Використайте функцію `int zisti_prvocislo(int cislo)`, яка повертає `1` для простого числа, інакше `-1`. **Врахуйте межі** — перше число може бути більшим за друге. Якщо в проміжку немає простих чисел, виведіть `Prvocislo neexistuje`.

### Приклад вводу
```
1 4
```
### Вивід
```
2
3
```
