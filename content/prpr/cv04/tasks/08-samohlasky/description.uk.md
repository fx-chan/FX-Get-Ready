Порахуйте у файлі `vstup.txt` голосні, приголосні та цифри (малі й великі літери). Використайте, напр., рядки:

```c
char samohlasky[]  = "aeiouyAEIOUY";
char spoluhlasky[] = "bcdfghjklmnpqrstvwxzBCDFGHJKLMNPQRSTVWXZ";
char cislice[]     = "0123456789";
```

Виведіть: `Pocet samohlasok: S, pocet spoluhlasok: H, pocet cislic: C.`

### Файл vstup.txt
```
Ahoj 125
```
### Вивід
```
Pocet samohlasok: 2, pocet spoluhlasok: 2, pocet cislic: 3.
```
