Spočítajte v súbore `vstup.txt` samohlásky, spoluhlásky a číslice (malé aj veľké písmená).
Použite napr. reťazce:

```c
char samohlasky[]  = "aeiouyAEIOUY";
char spoluhlasky[] = "bcdfghjklmnpqrstvwxzBCDFGHJKLMNPQRSTVWXZ";
char cislice[]     = "0123456789";
```

Vypíšte: `Pocet samohlasok: S, pocet spoluhlasok: H, pocet cislic: C.`

### Súbor vstup.txt
```
Ahoj 125
```
### Výstup
```
Pocet samohlasok: 2, pocet spoluhlasok: 2, pocet cislic: 3.
```
