Зчитайте дійсне число `x` і запишіть у файл `nasobky.txt` його кратні від 1 до 10. Рядок `i` має вигляд `i * x = ix`, де `i` на **2 позиції** (`%2d`), `x` і `ix` з 2 знаками після коми.

Щоб результат можна було перевірити, потім **закрийте файл, відкрийте знову для читання й виведіть його вміст на екран**.

### Приклад вводу
```
2.5
```
### Вивід (= вміст файлу)
```
 1 * 2.50 = 2.50
 2 * 2.50 = 5.00
 ...
10 * 2.50 = 25.00
```
