Načítajte zo stdin jeden znak. Potom čítajte znaky zo súboru `znak.txt`:

- ak bol načítaný znak `s`, zapisujte ich do súboru `novy.txt`; nakoniec vypíšte
  `Skopirovane do novy.txt:` a obsah súboru `novy.txt` (otvorte ho znova na čítanie),
- inak vypisujte znaky priamo na obrazovku.

V oboch prípadoch teda vznikne presná kópia obsahu `znak.txt`.

### Ukážka vstupu
```
s
```
### Súbor znak.txt
```
abrakadabra
bubu
```
### Výstup
```
Skopirovane do novy.txt:
abrakadabra
bubu
```
