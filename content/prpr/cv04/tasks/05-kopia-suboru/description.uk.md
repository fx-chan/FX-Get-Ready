Зчитайте зі stdin один символ. Потім читайте символи з файлу `znak.txt`:

- якщо зчитано символ `s`, записуйте їх у файл `novy.txt`; наприкінці виведіть `Skopirovane do novy.txt:` і вміст файлу `novy.txt` (відкрийте його знову для читання),
- інакше виводьте символи прямо на екран.

Тож в обох випадках утворюється точна копія вмісту `znak.txt`.

### Приклад вводу
```
s
```
### Файл znak.txt
```
abrakadabra
bubu
```
### Вивід
```
Skopirovane do novy.txt:
abrakadabra
bubu
```
