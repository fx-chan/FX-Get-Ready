Program **nečíta stdin**. Porovnajte súbory `prvy.txt` a `druhy.txt` znak po znaku.

- Ak majú rovnaký obsah, vypíšte `Subory su identicke`.
- Inak vypíšte `Pocet roznych znakov: ` a počet pozícií `i`, kde oba súbory majú `i`-ty znak a znaky
  sa líšia. Ak sú súbory rôzne dlhé, pridajte riadok `Jeden zo suborov je dlhsi o x znakov`.

### Súbory (bez koncového nového riadku)
```
prvy.txt:  ahoj
druhy.txt: ahujx
           *
```
### Výstup
```
Pocet roznych znakov: 1
Jeden zo suborov je dlhsi o 3 znakov
```
