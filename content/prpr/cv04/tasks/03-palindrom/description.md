Napíšte funkciu `long reverzne_cislo(long x)`, ktorá vráti číslo s opačným poradím cifier.
Program číta **všetky** nezáporné čísla zo vstupu (počet nie je známy — využite návratovú hodnotu
`scanf`). Pre každé vypíše reverzné číslo a potom `Cislo X je palindrom` alebo
`Cislo X nie je palindrom`.

### Ukážka vstupu
```
12345
12321
```
### Výstup
```
54321
Cislo 12345 nie je palindrom
12321
Cislo 12321 je palindrom
```
