Напишіть функцію `long reverzne_cislo(long x)`, яка повертає число з оберненим порядком цифр. Програма читає **всі** невід'ємні числа з вводу (кількість невідома — використайте значення, що повертає `scanf`). Для кожного виводить обернене число, а потім `Cislo X je palindrom` або `Cislo X nie je palindrom`.

### Приклад вводу
```
12345
12321
```
### Вивід
```
54321
Cislo 12345 nie je palindrom
12321
Cislo 12321 je palindrom
```
