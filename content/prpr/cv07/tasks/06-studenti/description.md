*Extra úloha k prednáške P7.* Definujte `typedef struct { char meno[51]; int body; } STUDENT;`.
Načítajte `n` (`n ≤ 100`) a potom `n` riadkov `meno body`. Vypíšte študenta s najviac bodmi (pri zhode
prvého) a priemer bodov na 2 desatinné miesta. Napíšte funkciu `STUDENT *najlepsi(STUDENT *s, int n)`.

### Ukážka vstupu
```
3
Ana 78
Boris 91
Cyril 64
```
### Výstup
```
Najlepsi: Boris (91 b.)
Priemer: 77.67
```
