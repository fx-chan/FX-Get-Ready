*Додаткова задача до лекції P6.* Напишіть **рекурсивну** функцію `long fib(int n)`, де `fib(0) = 0`, `fib(1) = 1` і `fib(n) = fib(n-1) + fib(n-2)`. Для кожного `n` на вводі (`0 ≤ n ≤ 30`, до кінця вводу) виведіть `fib(n) = hodnota`.

### Приклад вводу
```
0 1 10
```
### Вивід
```
fib(0) = 0
fib(1) = 1
fib(10) = 55
```
