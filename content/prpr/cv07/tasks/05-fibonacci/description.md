*Extra úloha k prednáške P6.* Napíšte **rekurzívnu** funkciu `long fib(int n)`, kde `fib(0) = 0`,
`fib(1) = 1` a `fib(n) = fib(n-1) + fib(n-2)`. Pre každé `n` na vstupe (`0 ≤ n ≤ 30`, až do konca
vstupu) vypíšte `fib(n) = hodnota`.

### Ukážka vstupu
```
0 1 10
```
### Výstup
```
fib(0) = 0
fib(1) = 1
fib(10) = 55
```
