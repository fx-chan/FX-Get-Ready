Створіть структуру для особи: ім'я та прізвище (макс. 100 символів), вулиця (макс. 100 символів), поштовий індекс і номер телефону (рядки). У статичному масиві на **10 осіб** збережіть `n` осіб (`n ≤ 10`) і виведіть їх.

Ввід: `n`, далі для кожної особи **4 рядки**: ім'я та прізвище, вулиця, індекс, телефон (ім'я і вулиця можуть містити пробіли — читайте цілі рядки через `fgets`).

### Приклад вводу
```
2
Jan Novak
Hlavna 12
81101
0901123456
Eva Mala
Dlha 3
04001
0944000111
```
### Вивід
```
1. Jan Novak, Hlavna 12, 81101, tel. 0901123456
2. Eva Mala, Dlha 3, 04001, tel. 0944000111
```
