Для кожного додатного цілого числа `N` на вводі (обробіть **усі** числа) створіть матрицю `N × N` і заповніть її літерами `a`, `b`, …, `z`, `a`, … «змійкою»: парні рядки (від 0) зліва направо, непарні справа наліво. Виведіть матрицю (літери через пробіл), а після неї порожній рядок.

### Приклад вводу
```
3
6
```

a b c
