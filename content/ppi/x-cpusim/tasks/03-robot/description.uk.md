Карта має $R$ рядків (адреса 1025) і $C$ стовпців (1026), $1 \le R, C \le 10$. Робот починає в клітинці (рядок 1027, стовпець 1028); рядки зростають вниз, стовпці вправо, нумерація з 1. Від адреси 1200 лежать команди, що закінчуються маркером $-1$: 0 = стоїть, 1 = вгору, 2 = вниз, 3 = вліво, 4 = вправо. Рух за межі карти ігнорується (робот залишається на місці).

| адреса | вихід |
|---|---|
| 1040 | кількість успішних кроків |
| 1041 | час = кількість оброблених команд (без маркера) |
| 1042 | кінцевий рядок |
| 1043 | кінцевий стовпець |

Приклад: карта $3 \times 4$, старт $(2, 2)$, команди `1, 1, 4, 4, 4, 0, 2, 3, -1`. Друга команда 1 вийшла б за межі карти, третя команда 4 вперлася б у край. Результат: 1040 = 5, 1041 = 8, 1042 = 2, 1043 = 3.
