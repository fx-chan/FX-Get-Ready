| адреса | значення |
|---|---|
| 1040 | кількість усіх команд (без маркера) |
| 1041 | кількість команд 1 |
| 1042 | кількість команд 2 |
| 1043 | кількість команд 3 |
| 1044 | кількість команд 4 |

Приклад: `0, 4, 1, 3, 1, 4, 2, 4, -1` → 1040 = 8, 1041 = 2, 1042 = 1, 1043 = 1, 1044 = 3.
