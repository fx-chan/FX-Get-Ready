Новий варіант у стилі тестів Sokoban/Tetris/Змійка. Час 100 хвилин. Розв'язуйте в CPUSim (cpusim.ail-lab.fiit.stuba.sk), потім скопіюйте програму сюди. Оцінюється приклад із завдання та приховані вхідні дані.

### Завдання

Запрограмуйте симуляцію крижаної поверхні: гравець після команди ковзає в один бік, доки не вдариться, дорогою збирає монети, а гра закінчується перемогою, коли він входить на вихід.

### Вхідні дані та пам'ять

| адреса | вміст |
|---|---|
| 1025, 1026 | кількість рядків $R$ і стовпців $C$, $3 \le R, C \le 10$ |
| 1027, 1028 | стартовий рядок і стовпець гравця (не на стіні й не на виході) |
| 1100 – 1199 | місцевість по рядках, $1100 + (r-1) \cdot C + (c-1)$: 0 = лід, 1 = стіна, 2 = вихід; не змінюється |
| 1200 – 1799 | команди, що закінчуються $-1$: 0 = стоїть, 1 = вгору, 2 = вниз, 3 = вліво, 4 = вправо |
| 1800 – 1899 | монети, $1800 + (r-1) \cdot C + (c-1)$: 1 = монета; зібрані монети перезапишіть на 0 |
| 1900 – 2047 | вільні робочі комірки |

### Правила

- Команда 1 – 4: гравець повторно зсувається на клітинку в заданому напрямку, доки наступна клітинка є на карті й не є стіною. Якщо вже перша клітинка не підходить, гравець стоїть.
- На кожній клітинці, на яку дорогою входить, він забирає монету (якщо вона там є).
- Коли гравець входить на вихід, він зупиняється на ньому й настає **перемога**; симуляція одразу завершується.
- **Хід** — це команда, під час якої гравець зсунувся принаймні на одну клітинку. **Час** зростає на 1 за кожну оброблену команду (також 0 і заблоковану); маркер $-1$ не враховується.

### Виходи

| адреса | значення |
|---|---|
| 1040 | зібрані монети |
| 1041 | ходи |
| 1042 | час |
| 1043 | перемога (1/0) |
| 1044, 1045 | кінцевий рядок і стовпець гравця |

### Приклад

$R = 5$, $C = 6$, старт $(5, 1)$, команди `4, 1, 0, 1, 3, 4, 2, 1, -1`. Місцевість (`#` стіна, `E` вихід):

```
 1: . . . . . .
 2: . # . . . .
 3: . . . . # E
 4: # . . . . .
 5: . . . # . .
```

Монети:

```
 1: 0 0 0 0 0 0
 2: 0 0 1 0 0 0
 3: 0 0 0 0 0 0
 4: 0 0 0 0 0 1
 5: 0 0 1 0 0 0
```

Результат: `2, 5, 7, 1, 3, 6` — гравець збирає монети на $(5, 3)$ і $(2, 3)$, четверта команда (вгору в першому рядку) заблокована, сьома довозить його на вихід, а остання команда вже не читається. Монета на $(4, 6)$ залишається.
