Nový variant v štýle testov Sokoban/Tetris/Hadík. Čas 100 minút. Riešte v CPUSime
(cpusim.ail-lab.fiit.stuba.sk), program potom skopírujte sem. Hodnotí sa príklad zo zadania aj skryté vstupy.

### Úloha

Naprogramujte simuláciu ľadovej plochy: hráč sa po príkaze šmýka jedným smerom, kým nenarazí,
cestou zbiera mince a hra končí výhrou, keď vojde na východ.

### Vstupy a pamäť

| adresa | obsah |
|---|---|
| 1025, 1026 | počet riadkov $R$ a stĺpcov $C$, $3 \le R, C \le 10$ |
| 1027, 1028 | štartový riadok a stĺpec hráča (nie na stene ani na východe) |
| 1100 – 1199 | terén po riadkoch, $1100 + (r-1) \cdot C + (c-1)$: 0 = ľad, 1 = stena, 2 = východ; nemení sa |
| 1200 – 1799 | príkazy ukončené $-1$: 0 = stoj, 1 = hore, 2 = dole, 3 = vľavo, 4 = vpravo |
| 1800 – 1899 | mince, $1800 + (r-1) \cdot C + (c-1)$: 1 = minca; zobraté mince prepíšte na 0 |
| 1900 – 2047 | voľné pracovné bunky |

### Pravidlá

- Príkaz 1 – 4: hráč sa opakovane posúva o políčko v danom smere, kým je ďalšie políčko v mape a nie je
  stena. Ak hneď prvé políčko nevyhovuje, hráč stojí.
- Na každom políčku, na ktoré cestou vojde, zoberie mincu (ak tam je).
- Keď vojde na východ, zastaví sa na ňom a nastane **výhra**; simulácia sa hneď končí.
- **Ťah** je príkaz, pri ktorom sa hráč posunul aspoň o jedno políčko. **Čas** rastie o 1 za každý
  spracovaný príkaz (aj 0 a zablokovaný); značka $-1$ sa nepočíta.

### Výstupy

| adresa | význam |
|---|---|
| 1040 | zobrané mince |
| 1041 | ťahy |
| 1042 | čas |
| 1043 | výhra (1/0) |
| 1044, 1045 | konečný riadok a stĺpec hráča |

### Príklad

$R = 5$, $C = 6$, štart $(5, 1)$, príkazy `4, 1, 0, 1, 3, 4, 2, 1, -1`. Terén (`#` stena, `E` východ):

```
 1: . . . . . .
 2: . # . . . .
 3: . . . . # E
 4: # . . . . .
 5: . . . # . .
```

Mince:

```
 1: 0 0 0 0 0 0
 2: 0 0 1 0 0 0
 3: 0 0 0 0 0 0
 4: 0 0 0 0 0 1
 5: 0 0 1 0 0 0
```

Výsledok: `2, 5, 7, 1, 3, 6` — hráč zoberie mince na $(5, 3)$
a $(2, 3)$, štvrtý príkaz (hore v prvom riadku) je zablokovaný, siedmy ho dovezie na východ a posledný
príkaz sa už nečíta. Minca na $(4, 6)$ ostane.
