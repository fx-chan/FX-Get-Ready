Завдання за фотографіями з тесту. 100 хвилин у базовому симуляторі CPUSim, 5 балів.

**Вхідні дані.** Карта має $R$ рядків (1025) і $C$ стовпців (1026), $3 \le R \le 10$, $5 \le C \le 10$. Гравець починає в (1027, 1028). Адреси 1029–1039 зарезервовані (нулі). Матриці збережено по рядках:

- місцевість від 1100: $1100 + (r-1) \cdot C + (c-1)$; 0 = вільно, 1 = стіна, 2 = ціль; не змінюється;
- ящики від 1800: $1800 + (r-1) \cdot C + (c-1)$; 1 = ящик; після завершення тут має бути кінцевий розклад.

Команди від 1200, що закінчуються $-1$: 0 = стоїть, 1 = вгору, 2 = вниз, 3 = вліво, 4 = вправо. Робочі комірки: 1900–2047.

**Правила.**

- Рух за межі карти або в стіну ігнорується.
- Ящик перед собою гравець штовхає на клітинку далі, якщо там є карта без стіни й без іншого ящика (ціль може бути); інакше нічого не відбувається. Два ящики одразу не штовхаються.
- **Крок** — це кожен рух, під час якого гравець справді зсувається. **Час** зростає на 1 за кожну оброблену команду (також 0 і заблоковану), маркер $-1$ не враховується.
- **Рахунок** = кількість ящиків на цілях (визначається вже з початкової карти).
- Коли всі ящики стоять на цілях, настає **перемога**, і симуляція одразу завершується (команда, що її спричинила, ще враховується). Перемога перевіряється й до першої команди — тоді кроки та час нульові.

| адреса | вихід |
|---|---|
| 1040 | рахунок |
| 1041 | кроки |
| 1042 | час |
| 1043 | перемога (1/0) |
| 1044, 1045 | кінцевий рядок і стовпець гравця |

**Приклад із завдання.** $R = 5$, $C = 7$, гравець $(3, 3)$, команди `0, 4, 1, 3, 1, 4, 2, 4, -1` (C = ціль, D = ящик, P = гравець):

```
 1: # # # # # # #
 2: # . . D C . #
 3: # . P D C . #
 4: # . . . . . #
 5: # # # # # # #
```

Шоста команда дотискає другий ящик на ціль → перемога, останні дві команди не читаються. Виходи 1040–1045: `2, 4, 6, 1, 2, 4`.
