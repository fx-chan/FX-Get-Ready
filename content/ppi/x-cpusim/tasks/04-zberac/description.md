Rozšírenie robota z predchádzajúcej úlohy (mapa, štart, príkazy rovnako). Terén je matica od adresy 1100
(0 = voľno, 1 = stena), mince sú v matici od adresy 1800 (1 = minca). Políčko $(r, c)$:

- terén: $1100 + (r-1) \cdot C + (c-1)$,
- mince: $1800 + (r-1) \cdot C + (c-1)$ — teda o 700 ďalej.

Do steny sa vstúpiť nedá (robot ostane stáť). Keď robot vstúpi na mincu, zoberie ju: v matici mincí sa
zapíše 0 a počet mincí sa zvýši. Terén sa nemení.

| adresa | výstup |
|---|---|
| 1040 | zobrané mince |
| 1041 | úspešné kroky |
| 1042 | čas (spracované príkazy) |
| 1043, 1044 | konečný riadok a stĺpec |

Príklad: mapa $4 \times 5$, štart $(4, 1)$, príkazy `1, 1, 4, 1, 4, 4, 4, 2, 3, -1`.

Terén:
```
 1: 0 0 0 0 0
 2: 0 1 1 0 0
 3: 0 0 0 1 0
 4: 0 0 0 0 0
```

Mince:
```
 1: 0 1 0 0 1
 2: 0 0 0 0 0
 3: 1 0 0 0 0
 4: 0 0 1 0 0
```

Výsledok: 1040 = 2, 1041 = 7, 1042 = 9,
1043 = 2, 1044 = 4; mince na $(3, 1)$ a $(1, 2)$ zmiznú z matice.
