Розширення робота з попереднього завдання (карта, старт, команди ті самі). Місцевість — матриця від адреси 1100 (0 = вільно, 1 = стіна), монети лежать у матриці від адреси 1800 (1 = монета). Клітинка $(r, c)$:

- місцевість: $1100 + (r-1) \cdot C + (c-1)$,
- монети: $1800 + (r-1) \cdot C + (c-1)$ — тобто на 700 далі.

У стіну увійти не можна (робот залишається на місці). Коли робот входить на монету, він її забирає: у матриці монет записується 0, а кількість монет збільшується. Місцевість не змінюється.

| адреса | вихід |
|---|---|
| 1040 | зібрані монети |
| 1041 | успішні кроки |
| 1042 | час (оброблені команди) |
| 1043, 1044 | кінцевий рядок і стовпець |

Приклад: карта $4 \times 5$, старт $(4, 1)$, команди `1, 1, 4, 1, 4, 4, 4, 2, 3, -1`.

Місцевість:
```
 1: 0 0 0 0 0
 2: 0 1 1 0 0
 3: 0 0 0 1 0
 4: 0 0 0 0 0
```

Монети:
```
 1: 0 1 0 0 1
 2: 0 0 0 0 0
 3: 1 0 0 0 0
 4: 0 0 1 0 0
```

Результат: 1040 = 2, 1041 = 7, 1042 = 9, 1043 = 2, 1044 = 4; монети на $(3, 1)$ і $(1, 2)$ зникнуть із матриці.
