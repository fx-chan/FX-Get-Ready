За адресою 1025 лежить кількість рядків $R$, за 1026 — кількість стовпців $C$ ($1 \le R, C \le 10$). Матрицю з нулів і одиниць збережено по рядках від адреси 1100. Запишіть кількість одиниць за адресою 1040, а кількість повних рядків (самі одиниці) — за адресою 1041.

Приклад ($R = 3$, $C = 4$):

```
 1: 1 1 1 1
 2: 0 1 0 0
 3: 1 1 1 1
```

Результат: 1040 = 9, 1041 = 2.
