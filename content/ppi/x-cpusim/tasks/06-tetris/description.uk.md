Завдання відтворено з пам'яті студентів; нечіткі місця тут доозначено так, щоб підходили обидва приклади.

**Вхідні дані.** Поле має $R$ рядків (1025) і $C$ стовпців (1026), $2 \le R \le 8$, $2 \le C \le 10$; нові блоки з'являються в стовпці $S$ (1027). Поле — матриця 0/1 по рядках з адресою клітинки $1100 + (r-1) \cdot C + c$ — тож починається на **1101**. Інструкції від 1200, що закінчуються $-1$: 0 = без зсуву, 1 = вліво, 2 = вправо. Робочі комірки від 1800.

**Правила.** Блок має розмір однієї клітинки.

1. Новий блок з'являється на $(1, S)$. Якщо там зайнято, гра закінчується поразкою (1043 = 1).
2. Перед кожною інструкцією перевіряється, чи блок стоїть — він в останньому рядку або під ним зайнята клітинка. Якщо так, він **осідає**: клітинка отримує 1, кількість блоків +1, інструкція не читається.
3. Якщо після осідання його рядок повний, увесь рядок обнуляється, а рахунок +1 (блоки над ним не падають, перевіряється лише цей рядок). Потім крок 1.
4. Якщо блок не стоїть, читається інструкція ($-1$ → кінець, 1043 = 0). Кількість циклів +1. За 1/2 блок зсувається вбік, якщо там немає краю чи зайнятої клітинки. Потім опускається на рядок, якщо під ним вільно. Продовжуємо кроком 2.

| адреса | вихід |
|---|---|
| 1040 | рахунок (видалені рядки) |
| 1041 | осілі блоки |
| 1042 | цикли (прочитані інструкції 0/1/2) |
| 1043 | кінець: 1 = поразка, 0 = маркер $-1$ |
| 1044, 1045 | рядок і стовпець активного блока |

**Приклад 1.** $R = C = 3$, $S = 2$, порожнє поле, `1, 0, 2, 0, 0, 0, 2, 1, 0, -1` → `1, 6, 9, 1, 1, 2`, у полі залишається повний стовпець 2.

**Приклад 2.** $R = C = 4$, $S = 2$, інструкції `2, 0, 0, 1, 1, 0, 0, 2, 2, 0, 0, -1`:

```
 1: 0 0 0 0
 2: 0 0 0 1
 3: 1 0 0 0
 4: 1 1 0 1
```

Виходи `1, 5, 11, 0, 2, 2`, поле після завершення:

```
 1: 1 0 0 0
 2: 1 0 0 1
 3: 1 0 1 0
 4: 0 0 1 0
```
