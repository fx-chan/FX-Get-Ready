## Шпаргалка: булева алгебра та способи запису функцій

- Закони де Моргана: $\overline{a + b} = \overline{a}\,\overline{b}$, $\overline{ab} = \overline{a} + \overline{b}$.
- Поглинання $a + ab = a$, поглинання заперечення $a + \overline{a}b = a + b$, склеювання $ab + a\overline{b} = a$, консенсус $ab + \overline{a}c + bc = ab + \overline{a}c$.
- Функцій від $n$ змінних є $2^{2^n}$, точок $2^n$; точку нумеруємо в двійковому записі, перша змінна має найбільшу вагу.
- Карта: код Грея 00, 01, 11, 10; кожна клітинка має $n$ сусідів, також через край.

::: quiz
Скільки сусідів має клітинка на карті 4 змінних?
- [ ] 2
- [ ] 3
- [x] 4
> Стільки, скільки є змінних: кожну можна змінити.
:::

## Шпаргалка: мінімізація та схеми

- Конфігурація з $2^s$ клітинок на карті $n$ змінних = добуток рангу $r = n - s$.
- MDNF: покрити **одиниці** якомога більшими й якомога меншою кількістю конфігурацій; MKNF: те саме з **нулями**, запис сумами (0 → змінна, 1 → заперечення).
- x (невизначені) використовуємо лише тоді, коли вони збільшують конфігурацію.
- NAND/NAND з MDNF, NOR/NOR з MKNF; однолітерний елемент іде в другий ступінь із запереченням.
- Статичний газард: сусідні одиниці без спільного добутку; BDNF їх покриває (додаємо консенсус).
- MUX: $2^m = n$ адресних і вхідних даних; DEMUX = MUX без OR; дешифратор «1 з n».

::: drill t-mdnf

::: quiz
$f = a\overline{b} + bc$. Який елемент треба додати до BDNF?
- [ ] $\overline{a}c$
- [x] $ac$
- [ ] $ab$
> Консенсус за змінною $b$: $a \cdot c$.
:::

## Шпаргалка: автомати та тригери

- Мілі $v: S \times X \to Y$, Мура $v: S \to Y$ (затримує вихід на такт).
- $Q^+$: D: $D$; T: $T \oplus Q$; JK: $J\overline{Q} + \overline{K}Q$; SR: $S + \overline{R}Q$, $SR = 0$.
- Обернена функція (0→0, 0→1, 1→0, 1→1): D: 0, 1, 0, 1; T: 0, 1, 1, 0; JK: 0x, 1x, x1, x0; SR: 0x, 10, 01, x0.
- Кількість тригерів $\lceil \log_2 |S| \rceil$; для тригера D є $D_i = Q_i^+$; невикористані коди = x.
- Кодування: правило 1 (однаковий наступний стан → сусідні коди), правило 2 (наступники того самого стану → сусідні).
- Період тактового сигналу $T \ge t_{PO} + t_K + t_s$.
- Асинхронні: стійкий стан $p(s, x) = s$, порядок $r = k_{max} + 1$, критичні гонки усуває прямий або непрямий код.

::: quiz

- [x] 1
> Доповнення: $0 \to 1$.
:::

::: quiz
Автомат має 9 станів. Найменша кількість тригерів —

- [x] 4

> $2^3 = 8 < 9 \le 16$.

## Шпаргалка: процесор

- Напівсуматор $S = A \oplus B$, $C = AB$; повний $S = A \oplus B \oplus C_{in}$, $C_{out}$ = мажоритарна функція.
- $A - B = A + \overline{B} + 1$; прапорці C (перенесення), Z (нуль), N (старший біт), V (хибний знак при однакових знаках доданків).
- 4-бітова інструкція код операції + ADR: 00 LDA, 01 ADD, 10 STA, 11 JMP; вибірка – декодування – виконання.
- Такти з MAR/MBR: вибірка 3, LDA і ADD разом 6, STA 5, JMP 4.
- Жорстка логіка: швидка, RISC; мікропрограма: гнучка, CISC.
