Тест містить 4 приклади, разом 12 відповідей. Час 60 хвилин. Заперечення `a'`, добуток `ab`, сума `a+b`, KNF `(a+b)(c+d')`, NAND `↑`, NOR `↓`.

### Приклад 1 — комбінаційна схема

$f(a, b, c, d) = \sum(1, 3, 5, 7, 8, 10, 12, 13, 14, 15)$.

### Приклад 2 — автомат

Автомат Мілі з входом $x$ зі стану $A$:

| стан | $x = 0$ | $x = 1$ |
|---|---|---|
| $A$ | $A$ / 0 | $B$ / 0 |
| $B$ | $C$ / 0 | $B$ / 0 |
| $C$ | $A$ / 1 | $B$ / 0 |

Кодування $A = 00$, $B = 01$, $C = 10$ ($Q_1Q_0$), код 11 не використовується. Змінні `Q1, Q0, x`.

### Приклад 3 — арифметика

4-бітовий суматор, числа в доповняльному коді. Прапорці як чотири біти **C Z N V**.

### Приклад 4 — процесор

Процесор з інструкціями LDA, ADD, STA, JMP (2 біти коду операції + 2 біти адреси) та з регістрами MAR, MBR.
