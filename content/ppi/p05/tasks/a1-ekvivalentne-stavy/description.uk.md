Два стани **еквівалентні**, якщо для довільної вхідної послідовності дають однаковий вихід. Еквівалентні стани можна об'єднати. Їх шукають послідовним розбиттям: спочатку за виходами, потім за тим, куди ведуть переходи.

| стан | $x = 0$ | $x = 1$ |
|---|---|---|
| $s_1$ | $s_2$ / 0 | $s_3$ / 0 |
| $s_2$ | $s_4$ / 1 | $s_3$ / 0 |
| $s_3$ | $s_2$ / 0 | $s_5$ / 1 |
| $s_4$ | $s_2$ / 1 | $s_5$ / 0 |
| $s_5$ | $s_4$ / 0 | $s_3$ / 1 |
